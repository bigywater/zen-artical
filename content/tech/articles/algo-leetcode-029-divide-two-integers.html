LeetCode 29. 两数相除

使用倍增而不是乘法和除法：不断把除数翻倍，找到当前能扣除的最大块，再累加商。

题目与官方入口

本篇保留题意摘要，完整约束请以官方页面为准：LeetCode 29 · 两数相除。

示例：dividend = 10，divisor = 3。页面中的结果由本机实际运行得到。

真实验证：核心思路与代码

使用倍增而不是乘法和除法：不断把除数翻倍，找到当前能扣除的最大块，再累加商。

代码 
dividend, divisor = 10, 3
sign = -1 if (dividend < 0) ^ (divisor < 0) else 1
a, b, quotient = abs(dividend), abs(divisor), 0
while a >= b:
    chunk, multiple = b, 1
    while a >= chunk + chunk:
        chunk += chunk; multiple += multiple
    a -= chunk; quotient += multiple
answer = sign * quotient
print(max(-2**31, min(2**31 - 1, answer)))

LeetCode 30. 串联所有单词的子串

按单词长度分组滑动窗口，用计数器记录窗口内单词；超出目标次数时从左侧移除。

题目与官方入口

本篇保留题意摘要，完整约束请以官方页面为准：LeetCode 30 · 串联所有单词的子串。

示例：s = barfoothefoobarman，words = [foo, bar]。页面中的结果由本机实际运行得到。

真实验证：核心思路与代码

按单词长度分组滑动窗口，用计数器记录窗口内单词；超出目标次数时从左侧移除。

代码 
from collections import Counter
s, words = 'barfoothefoobarman', ['foo', 'bar']
width, need = len(words[0]), Counter(words)
answer = []
for offset in range(width):
    left = offset; window = Counter(); count = 0
    for right in range(offset, len(s) - width + 1, width):
        word = s[right:right + width]
        if word not in need:
            left = right + width; window.clear(); count = 0; continue
        window[word] += 1; count += 1
        while window[word] > need[word]:
            old = s[left:left + width]; window[old] -= 1; left += width; count -= 1
        if count == len(words): answer.append(left)
print(answer)

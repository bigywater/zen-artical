异常

实测 · 本机执行输出 
    %d                     → IllegalFormatConversionException: d != java.lang.Double
    %d                     → IllegalFormatConversionException: d != java.lang.String
    %s %s                  → MissingFormatArgumentException: Format specifier '%s'
    %z                     → UnknownFormatConversionException: Conversion = 'z'
    %#d                    → FormatFlagsConversionMismatchException: Conversion = d, Flags = #
    %-d                    → MissingFormatWidthException: %-d
    %5                     → UnknownFormatConversionException: Conversion = '5'
    %.2d                   → IllegalFormatPrecisionException: 2
    %,s                    → FormatFlagsConversionMismatchException: Conversion = s, Flags = ,
    %d                     → "10"
    %d                     → "123456789012345678901234567890"
    %f                     → IllegalFormatConversionException: f != java.lang.Integer
    %d                     → "null"
    %s                     → "1"
  多余的参数不报错(最后一行 %s 只用了第一个);缺少参数、类型不符、格式符不认识、标志冲突才抛异常

Locale

实测 · 本机执行输出 
    en_US    %,d → 1,234,567        %.2f → 1234.50
    de_DE    %,d → 1.234.567        %.2f → 1234,50
    fr_FR    %,d → 1 234 567        %.2f → 1234,50
    hi_IN    %,d → 1,234,567        %.2f → 1234.50
    ar_EG    %,d → ١٬٢٣٤٬٥٦٧        %.2f → ١٢٣٤٫٥٠
    默认 Locale = en_CN;String.format("%.2f", 1234.5) = 1234.50(不指定 Locale 时用默认 Locale)
    大写转换也受 Locale 影响:Locale(tr) 下 String.format("%S", "i") = İ,US 下 = I

参数序号

实测 · 本机执行输出 
    %2$s %1$s              → "hello world"
    %1$s %1$s %1$s         → "echo echo echo"
    %s %<s %s              → "a a b"
    %2$s %s %s             → "y x y"
    %s %2$s %s             → "x y y"
    %3$s                   → MissingFormatArgumentException: Format specifier '%3$s'
  规则:普通的 %s 按顺序取参数,不受 %2$s 这种显式序号的影响;%<s 重复上一个格式符用过的参数
    %n 与 \n:a\nb vs a\nb(%n 是平台的行分隔符,macOS/Linux 上是 \n)
    Formattable 对象配合 %-10.3s:<自定义:flags=1,width=10,precision=3>

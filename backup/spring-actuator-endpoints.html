Actuator 端点:暴露、安全与开销

装了 Actuator 默认暴露什么?include=* 危险在哪?heapdump 和 shutdown 为什么默认打不开?env 里的密码会不会明文?单独的管理端口有什么坑?这篇在 Spring Boot 4.0.8 上逐个端点实测。

env 的脱敏

实测 · 本机执行输出 
  默认(management.endpoint.env.show-values 不设):
    app.name → 200,值 '******',来源 systemProperties
    app.password → 200,值 '******',来源 systemProperties
    app.token → 200,值 '******',来源 systemProperties
    app.url → 200,值 '******',来源 systemProperties
  management.endpoint.env.show-values=ALWAYS:
    app.name → 200,值 'demo',来源 systemProperties
    app.password → 200,值 'p@ssw0rd',来源 systemProperties
    app.token → 200,值 'tok-123',来源 systemProperties
    app.url → 200,值 'http://example.com',来源 systemProperties
  management.endpoint.env.show-values=WHEN_AUTHORIZED(没有装 Spring Security):
    app.name → 200,值 '******',来源 systemProperties
    app.password → 200,值 '******',来源 systemProperties
    app.token → 200,值 '******',来源 systemProperties
    app.url → 200,值 '******',来源 systemProperties

默认所有值脱敏;show-values=ALWAYS 全部明文;WHEN_AUTHORIZED 没有 Security 时仍脱敏。

管理端口

实测 · 本机执行输出 
  management.server.port=9608:业务端口 GET /actuator/health → 404;管理端口 GET /fast → 404;管理端口 GET /actuator/health:业务端口可连接之后又过了 261 ms 才连得上管理端口(此前连接被拒绝 11 次),第一次响应 → 503 {"groups":["liveness","readiness"],"status":"DOWN"},2 秒后 → 200 {"groups":["liveness","readiness"],"status":"UP"}
  management.endpoints.web.base-path=/ops:/actuator/health → 404;/ops/health → 200

管理端口比业务端口晚开,刚开时 health 返回 503 DOWN;base-path 可以改。

开销

实测 · 本机执行输出 
  没有 actuator:启动到端口可连接 中位 817 ms(范围 815~917);启动后常驻内存中位 168 MB
  有 actuator(默认):启动到端口可连接 中位 1082 ms(范围 972~1203);启动后常驻内存中位 184 MB

装 actuator 启动多约 265 ms、内存多约 16 MB(量级参考);请求吞吐开销没有得到可信结果。

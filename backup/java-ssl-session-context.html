SSLSessionContext:管理 TLS 会话缓存

调了会话缓存大小与超时,线上却没有任何变化?这篇用本机的 TLS 服务端把原因找出来:JDK 默认用会话票据,服务端 SSLSessionContext 里根本没有缓存。

0 个
默认设置下服务端 SSLSessionContext.getIds() 里的会话数(会话票据让服务端不缓存)
6 / 6 vs 0 / 6
服务端缓存设为 3、6 个客户端按序重连:默认设置(全部恢复)与关闭票据扩展后(全部完整握手)
0.88 vs 6.10 ms
TLS 1.2 恢复与完整握手的握手时间中位数(RSA-3072,本机回环)
← 上一篇 CRL 与 OCSP:证书撤销状态

LeetCode 86. 分隔链表

给定一个链表和一个值 x，把链表重新排列，使所有小于 x 的结点都排在大于或等于 x 的结点之前，并且保持每一部分里结点原来的相对顺序（稳定）。做法是拆成两条链：遍历原链表，小于 x 的接到 small 链的末尾，其余的接到 large 链的末尾，最后把 small 接上 large。用两个哑结点让"链是否为空"不需要特判。这道题有一个隐蔽的坑：大链的最后一个结点在原链表里可能还指向别的结点，如果不把它的 next 断开，拼起来的链表里会有环。本文用真实运行展示这个环，给出五种语言的实现，并把两条链的生长做成分步演示。

陷阱：大链的尾结点没有断开，会形成环

原链表里的结点是原样复用的，每个结点的 next 还指着它在原链表里的下一个结点。遍历时，大链的尾结点是原链表里最后一个大于等于 x 的结点，它的 next 可能指向一个已经被接到小链里的结点。如果不把 large.next 置空，最后拼出来的链表末尾会回到前面，形成环。下面是没有断开的写法的真实结果，我最多让它遍历 40 步，走了 40 步还没到尽头就判定为有环：

官方示例 [1, 4, 3, 2, 5, 2]（x = 3）：大链是 4 → 3 → 5，5 在原链表里后面还有一个 2（在小链里），没断开时 5 的 next 仍然指向 2，遍历得到 1, 2, 2, 4, 3, 5, 2, 4, 3, 5, ... 无限循环；[2, 1]（x = 2）同样出现环。而 [1, 2, 3]（x = 5，全部小于 x）、[5, 4, 3]（x = 1，全部大于等于 x）、[1, 4, 3, 2, 5, 2]（x = 9）里，大链要么为空，要么大链的尾结点本来就是原链表的最后一个结点（它的 next 本来就是空），所以不出问题。这个错误只在"大链尾结点后面在原链表里还有小结点"时才暴露。

拆成两条链再拼接：五种语言的实现

smallDummy、largeDummy 是两条链的哑头，small、large 是两条链当前的尾指针。遍历原链表的每个结点：值小于 x 接到 small 后面，否则接到 large 后面；这里没有新建结点，只是把原来的结点串起来。遍历结束后先把 large.next 置空，再把 small.next 指向大链的第一个结点（largeDummy.next），返回 smallDummy.next。Python、Java、Go、JavaScript、C++ 都是真实编译运行的；这个做法稳定，也只需要 O(1) 的额外空间（只有两个哑结点）。

Python · 解法代码class ListNode: def __init__(self, val=0, next=None): self.val = val self.next = next def partition_list(head, x): small_dummy, large_dummy = ListNode(), ListNode() # 两条链：小于 x 的、大于等于 x 的 small, large = small_dummy, large_dummy while head: if head.val < x: small.next = head # 依次接到各自的链尾，保持原来的相对顺序 small = small.next else: large.next = head large = large.next head = head.next large.next = None # 必须把大链的尾断开，否则可能残留指回小链的旧指针形成环 small.next = large_dummy.next # 小链接上大链 return small_dummy.next

Java · 解法代码class ListNode { int val; ListNode next; ListNode(int v) { val = v; } } class Solution { public ListNode partition(ListNode head, int x) { ListNode smallDummy = new ListNode(0), largeDummy = new ListNode(0); // 两条链：小于 x 的、大于等于 x 的 ListNode small = smallDummy, large = largeDummy; while (head != null) { if (head.val < x) { small.next = head; small = small.next; } // 依次接到各自的链尾，保持原来的相对顺序 else { large.next = head; large = large.next; } head = head.next; } large.next = null; // 必须把大链的尾断开，否则可能残留指回小链的旧指针形成环 small.next = largeDummy.next; // 小链接上大链 return smallDummy.next; } }

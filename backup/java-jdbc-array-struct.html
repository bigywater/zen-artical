JDBC Array 与 Struct:映射数据库复合类型

JDBC 的 Array 与 Struct 在不同数据库上的支持天差地别。这篇用 PostgreSQL 把数组用到极致,用 MySQL 看清「不支持」是什么样子,并检查复合类型能走到哪一步。

4.40 vs 10.17 ms
10000 个 id 的查询:= ANY(?) 数组参数与 IN (?,…) 占位符列表(PG)
aced0005
MySQL 上 setObject(Integer[]) 发给服务器的数据开头(Java 序列化魔数,不报错)
PGobject
PG 复合类型 getObject 的返回类型(不是 java.sql.Struct;createStruct 与 getObject(Struct.class) 都不支持)

LeetCode 36. 有效的数独

给定一个 9×9 的数独棋盘，只需要判断已经填入的数字是否有效：每一行、每一列、每一个 3×3 的宫里，数字 1 到 9 都不能重复。棋盘不一定能被解出来，只检查已填的部分有没有冲突。做法是扫描一遍，用三组位掩码分别记录每行、每列、每个宫里出现过的数字，遇到冲突就返回。本文用真实的随机棋盘展示"只检查行和列、漏掉宫"的错误有多常见，给出五种语言的实现，并把扫描和冲突检测做成分步演示。

陷阱：只查行和列，漏掉宫

行和列的检查很自然，容易漏掉 3×3 的宫。我用与对拍相同的随机棋盘生成器（从合法的完整数独出发，随机保留部分格子，再随机改写一两个格子）生成了 20000 个棋盘，看看只检查行和列的写法会漏掉多少：

真实实测 · 本机执行输出
随机 20000 个棋盘，其中 7879 个不合法（违反行、列、宫三条规则之一）；
只检查行和列、不检查 3×3 宫的写法：其中 652 个不合法的棋盘被误判成合法（占不合法棋盘的 8.3%）。

20000 个棋盘里有 7879 个不合法，其中 652 个（8.3%）是只违反宫规则、行和列都没有冲突的，只查行列的写法把它们误判成了合法。用例里也专门放了一组这样的数据：同一个宫里的两个 5，行、列都不同。

位掩码扫描：五种语言的实现

用三个长度为 9 的整数数组 rows、cols、boxes，每个整数的第 d 位表示数字 d 是否在这一行、这一列、这一宫里出现过。宫的编号是 r / 3 * 3 + c / 3。逐格扫描，空格跳过；遇到数字 d，看它对应的行、列、宫的掩码里第 d 位是否已经是 1，是就冲突，返回失败；否则把三个掩码的第 d 位置为 1。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(board): rows, cols, boxes = [0] * 9, [0] * 9, [0] * 9 # 每一行、每一列、每个 3×3 宫各用一个 9 位的位掩码记录出现过的数字 for r in range(9): for c in range(9): ch = board[r][c] if ch == ".": continue bit = 1 << int(ch) b = r // 3 * 3 + c // 3 # (r, c) 所在的宫编号 0..8 if rows[r] & bit or cols[c] & bit or boxes[b] & bit: return False rows[r] |= bit cols[c] |= bit boxes[b] |= bit return True

Java · 解法代码class Solution { public boolean isValidSudoku(char[][] board) { int[] rows = new int[9], cols = new int[9], boxes = new int[9]; // 每行、每列、每个宫各用一个位掩码 for (int r = 0; r < 9; r++) { for (int c = 0; c < 9; c++) { char ch = board[r][c]; if (ch == '.') continue; int bit = 1 << (ch - '0'); int b = r / 3 * 3 + c / 3; // (r, c) 所在的宫编号 0..8 if ((rows[r] & bit) != 0 || (cols[c] & bit) != 0 || (boxes[b] & bit) != 0) return false; rows[r] |= bit; cols[c] |= bit; boxes[b] |= bit; } } return true; } }

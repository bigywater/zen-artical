Associated Type

关联类型和泛型参数都能让 trait「带一个类型」,但它们的语义不同:关联类型是「这个类型实现 trait 时确定的一个类型」。这篇用编译器的报错把两者的区别摆出来,再看约束里的几种写法和标准库里最常见的三个关联类型。

E0119
关联类型的 trait 对同一类型只能实现一次
E0283
泛型参数的 trait 多次实现后调用要标注类型
Item / Target / Output
标准库里最常见的三个关联类型
← 上一篇 dyn Trait 的对象安全

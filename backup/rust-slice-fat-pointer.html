Slice 的胖指针

&v[2..7] 是怎么做到不复制的?切片里到底存了什么?越界会怎样?空切片和零大小元素的切片指针又是什么?这篇把切片拆成「指针 + 长度」逐项验证。

16 字节
&[T] 的大小(指针 + 长度)
0 次复制
切出子切片时被复制的元素数
0x8
空 &[u64] 的指针(非空、对齐的悬空地址)

零大小与空切片

实测 · 本机执行输出 
  编译:成功
  运行(退出码 0):
      &[()] 长度 1000000,size_of_val = 0 字节(100 万个零大小元素不占内存)
      空切片 &[u64] 的指针 0x8:非空 true,对齐到 8: true(指向「一个对齐的悬空地址」,没有内存可读)

0x8 是这台机器上 u64 空切片的占位地址,是实现细节,换类型或平台可能不同。

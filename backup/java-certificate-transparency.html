证书透明度:如何验证证书发布记录

证书透明度(CT)把“证书已经公开登记”变成可验证的事实。这篇用真实的证书、真实的日志列表和真实的日志服务器,在 Java 里完成它的三步验证:SCT 的签名、日志的 STH 签名、Merkle 包含证明,并确认 JDK 的 TLS 默认不做这些。

    本文用到的工具与边界

    • 本机 macOS 27 arm64 / OpenJDK(Temurin 17.0.20、Homebrew 21.0.12 与 27,每篇注明实际用的版本);用 javac 编译、java 直接运行,需要第三方库时用 Maven 解析依赖;计时用 System.nanoTime,数字每次运行会有小幅抖动。JDK 21.0.12 + BouncyCastle 1.78.1(只用来解析与重组 TBSCertificate)与 Jackson;证书由 openssl 4.0.3 s_client 经本机代理取回,日志列表来自 gstatic.com,日志请求(get-sth / get-proof-by-hash / get-entries)发往 ct.googleapis.com;数字是 2026-10-05 当天取到的真实数据
    • 没有验证:外部嵌入 SCT 之外的传递方式(TLS 扩展、OCSP 装订)、静态 CT API(Sunlight / tiles)的日志、一致性证明(get-sth-consensus)、监控与域名告警、SCT 数量策略(Chrome / Apple 的要求)、日志列表之外的日志(wikipedia 的第二个 SCT)

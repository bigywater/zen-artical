Java 属性测试

属性测试不是写几个例子,而是描述一条对所有输入都成立的规律,让框架去找反例。找到之后怎么收缩成最小的反例?下次怎么复现?边界值怎么混进随机数据?这篇用三个故意写错的函数逐个演示。

12 步
平均值缺陷的反例从 (-2147483648, -58912738) 收缩到 (-1, -2147483648) 用的步数
1 次
第二次运行时 jqwik 从 .jqwik-database 重放失败样本后失败的调用数
8 步
排序缺陷从 11 个元素的列表收缩到 [0, 0, 0, 0, 0, 0] 的步数

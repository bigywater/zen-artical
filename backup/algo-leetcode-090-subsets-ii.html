LeetCode 90. 子集 II

给定一个可能包含重复元素的整数数组，返回它所有可能的子集（幂集），子集不能重复（[1, 2] 和 [2, 1] 只算一个，两个 2 各自被选中但内容相同的子集也只算一个）。这是第 78 题（无重复元素）的进阶，去重的办法和"组合总和 II"、"全排列 II"一脉相承：先排序，让相同的数挨在一起，然后在回溯的同一层里，遇到与前一个相同的数就跳过（同一层已经把"选这个数"的情形处理过了）。本文用真实数据展示第 78 题的写法直接用在这里会得到多少重复子集，给出五种语言的实现，并把跳过的过程做成分步演示。

陷阱：直接沿用第 78 题的写法，会得到重复的子集

第 78 题的回溯里，每个元素当作互不相同的，选不同下标的两个相同的数得到的子集内容一样，但会被当成两个不同的结点。下面是没有"同层跳过"的写法与 solve 的真实结果：

排序加同层跳过：五种语言的实现

先排序。dfs(start) 进入时先把当前路径收集一份（每个结点本身就是一个子集）；然后对 i 从 start 到末尾：如果 i > start 并且 nums[i] == nums[i - 1]，说明同一层里前一个相同的数已经作为"这一位"试过了，跳过；否则把 nums[i] 加入路径，递归 dfs(i + 1)，返回后撤销。注意条件是 i > start，而不是 i > 0：start 是这一层的起点，这一层里的第一个数不能跳过，否则 [1, 2, 2] 里选两个 2 的子集 [2, 2] 会丢掉。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(nums): nums = sorted(nums) # 排序：让相同的数挨在一起 res, path = [], [] def dfs(start): res.append(path[:]) # 每个结点本身就是一个子集 for i in range(start, len(nums)): if i > start and nums[i] == nums[i - 1]: # 同一层里，相同的数只作为"这一位"试一次，否则会得到重复的子集 continue path.append(nums[i]) dfs(i + 1) path.pop() dfs(0) return res

Java · 解法代码class Solution { public List<List<Integer>> subsetsWithDup(int[] nums) { Arrays.sort(nums); // 排序：让相同的数挨在一起 List<List<Integer>> res = new ArrayList<>(); dfs(nums, 0, new ArrayList<>(), res); return res; } private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) { res.add(new ArrayList<>(path)); // 每个结点本身就是一个子集 for (int i = start; i < nums.length; i++) { if (i > start && nums[i] == nums[i - 1]) continue; // 同一层里，相同的数只试一次，否则会得到重复的子集 path.add(nums[i]); dfs(nums, i + 1, path, res); path.remove(path.size() - 1); } } }

分步演示：[1, 2, 2]

下面的演示用官方示例 [1, 2, 2]（已经有序）。深度优先地走：空集 → [1] → [1, 2] → [1, 2, 2]；回退到 [1] 这一层，下一个是下标 2 的 2，它与同一层前一个（下标 1 的 2）相同，被跳过（淡色）；再回退到根，选下标 1 的 2 得到 [2]，继续得到 [2, 2]；最后根这一层的下标 2 的 2 同样被跳过。共 6 个子集。每一帧都是把上面的解法在这组输入上真实执行记录下来的，运行器还检查了演示最终得到的子集集合与 solve 的返回值一致。

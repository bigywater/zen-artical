LeetCode 65. 有效数字

给定一个字符串，判断它是否是一个有效的数字。有效数字由可选的符号、一个数字部分（整数，或者带小数点的小数，小数点前后至少有一侧有数字）、和可选的指数部分（e 或 E，后面跟可选的符号和至少一位整数）组成，中间不能有空格。规则不多，但细节很杂："4." 和 ".5" 合法，"." 和 "e3" 不合法，"1e" 不合法，"1.5.5" 不合法。本文给出一个从左到右的手写扫描器，与一条正则表达式对拍，用真实数据展示"用语言内置的转数字函数来判断"为什么不行，给出五种语言的实现，并把扫描的阶段做成分步演示。

题意与示例

完整题目见官方页面（链接在文末）。这道题只涉及十进制，字符只有数字、+、-、.、e、E。基准解是一条正则表达式 [+-]?(\d+\.?\d*|\.\d+)([eE][+-]?\d+)?，要求整个字符串完全匹配，与手写的扫描器是两种独立的写法。一共 32 组用例，覆盖官方所有的合法和不合法示例，以及空串、只有符号、指数缺少数字、多个小数点、首尾有空格等情形：

陷阱：语言内置的转换函数接受的范围更广

一个偷懒的想法是尝试把字符串转成浮点数，能转成功就是有效数字。但各语言的转换函数都比这道题的规则宽松。下面在 Python 里用 float() 做对比：

float() 接受 inf、-Infinity、nan、带下划线的 1_000、首尾有空格的 1 ，甚至阿拉伯-印度数字 ٣（Unicode 里的数字 3），而这道题都不认为是有效数字；两者不一致的输入一共 6 个。0x10、e5、5e 这几个 float() 也拒绝，与本文的规则一致。这个对比只在 Python 里做了，其他语言的转换函数各有各的宽松规则，这里没有实测。

手写扫描器：五种语言的实现

从左到右一个指针 i。第一步：可选的符号。第二步：数字部分：连续读取数字和至多一个小数点，同时统计数字个数；如果数字个数是 0（例如只有一个 .），不合法。第三步：如果下一个字符是 e 或 E，读指数部分：可选的符号，然后必须至少有一位数字，否则不合法。最后要求指针刚好走到字符串末尾，否则说明后面还有多余的字符。字符判断只接受 ASCII 的 0 到 9。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(s): n = len(s) i = 0 if i < n and s[i] in "+-": # 可选的符号 i += 1 digits, seen_dot = 0, False while i < n and ("0" <= s[i] <= "9" or (s[i] == "." and not seen_dot)): # 数字和至多一个小数点 if s[i] == ".": seen_dot = True else: digits += 1 i += 1 if digits == 0: # 小数点前后至少要有一位数字（"." 不合法） return False if i < n and s[i] in "eE": # 可选的指数部分 i += 1 if i < n and s[i] in "+-": i += 1 exp_digits = 0 while i < n and "0" <= s[i] <= "9": # 指数必须是整数，且至少一位 exp_digits += 1 i += 1 if exp_digits == 0: return False return i == n # 必须刚好消耗完整个字符串

Java · 解法代码class Solution { public boolean isNumber(String s) { int n = s.length(), i = 0; if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) i++; // 可选的符号 int digits = 0; boolean seenDot = false; while (i < n && ((s.charAt(i) >= '0' && s.charAt(i) <= '9') || (s.charAt(i) == '.' && !seenDot))) { // 数字和至多一个小数点 if (s.charAt(i) == '.') seenDot = true; else digits++; i++; } if (digits == 0) return false; // 小数点前后至少要有一位数字（"." 不合法） if (i < n && (s.charAt(i) == 'e' || s.charAt(i) == 'E')) { // 可选的指数部分 i++; if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) i++; int expDigits = 0; while (i < n && s.charAt(i) >= '0' && s.charAt(i) <= '9') { // 指数必须是整数，且至少一位 expDigits++; i++; } if (expDigits == 0) return false; } return i == n; // 必须刚好消耗完整个字符串 } }

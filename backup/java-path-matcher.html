PathMatcher:文件匹配模式的边界

glob 看起来像 shell 通配符,但 PathMatcher 的规则有不少细节:匹配的是整个路径、* 不跨目录、** 与 ** / 的差别、大小写、取反写法。这篇用一张匹配矩阵与几个目录实例逐项验证。

· vs ✓
**/*.java 对顶层的 Main.java 为假(需要 {*.java,**/*.java} 或 **.java)
[^A-M]
在 glob 里不是取反(匹配 Main.java),取反要写 [!A-M]
0 个
walk 里用「绝对路径」去匹配 *.java 的结果(要么用 getFileName(),要么用 **.java)

大小写

实测 · 本机执行输出 
  [case]
    FileSystem:MacOSXFileSystem;separator = /
        glob:*.JAVA         匹配 a.java   → false
        glob:*.java         匹配 A.JAVA   → false
        glob:[A-Z].java     匹配 a.java   → false
        glob:{A,b}.java     匹配 a.java   → false
        glob:main.java      匹配 Main.java → false
    文件系统本身是否区分大小写(Files.exists(hello.txt),实际文件是 Hello.txt):true;isSameFile 两者 = true
    newDirectoryStream(dir, "hello.*") 返回 [](glob 区分大小写,即使文件系统不区分)
    newDirectoryStream(dir, "Hello.*") 返回 [Hello.txt]
    regex 想忽略大小写:regex:(?i).*\.JAVA → true

转义与分隔符

实测 · 本机执行输出 
  [escape]
        glob:\*.java      匹配 *.java    → true
        glob:\*.java      匹配 a.java    → false
        glob:a\?b         匹配 a?b       → true
        glob:a\?b         匹配 axb       → false
        glob:\{a\}        匹配 {a}       → true
        glob:[*]          匹配 *         → true
        glob:[?]x         匹配 ?x        → true
        glob:[{]          匹配 {         → true
        glob:a/b          匹配 a/b       → true
        glob:*            匹配 a/b       → false
        glob:?            匹配 /         → false
        glob:a?b          匹配 a/b       → false
    regex 匹配的是 Path.toString() 的整串:regex:.*\.java 对 src/Main.java → true;regex:src/.*  对 src/a/b.java → true;regex:\.java 对 Main.java(不是整串)→ false
    Path.toString 的归一化:Paths.get("src//a///b.java") = src/a/b.java;Paths.get("src/a/") = src/a;g("src/*").matches(Paths.get("src//a")) = true

目录中的用法

实测 · 本机执行输出 
  [stream]
    newDirectoryStream(root, "*.java") = [.d.java, a.java](只有一层;.d.java 也在内——隐藏文件不特殊)
    newDirectoryStream(root, "**.java") = [.d.java, a.java](流里每个条目的文件名与 glob 比较,不会进入子目录)
    newDirectoryStream(root, "{a,b}.*") = [a.java, b.class]
    newDirectoryStream(root, "*/") 条目数 0
    walk + glob:**/*.java              用「相对路径」匹配 → [sub/deep/g.java, sub/e.java]
    walk + glob:{*.java,**/*.java}     用「相对路径」匹配 → [.d.java, a.java, sub/deep/g.java, sub/e.java]
    walk + glob:**.java                用「相对路径」匹配 → [.d.java, a.java, sub/deep/g.java, sub/e.java]
    walk + glob:*.java                 用「相对路径」匹配 → [.d.java, a.java]
    walk + glob:**.java 用「绝对路径」匹配:[.d.java, a.java, sub/deep/g.java, sub/e.java](** 可以吞掉绝对路径的前缀目录)
    walk + glob:*.java 用绝对路径匹配:0 个

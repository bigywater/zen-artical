async/await 状态机

.await 背后到底发生了什么?编译器把 async fn 变成一个枚举状态机,每个 await 点是一个状态,跨 await 的局部变量存在 Future 里。这篇用 size_of_val 直接量出状态机的大小,再验证它如何保存状态、为什么不能递归、为什么需要 Pin。

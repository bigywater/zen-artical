KeyPairGenerator:生成公钥和私钥

生成密钥对只有两行代码,但默认值、边界和耗时都有细节。这篇用多个 JDK 版本和 OpenSSL 量出:默认参数怎么随版本变化,RSA 与 EC 能接受什么参数,生成耗时的波动,以及固定种子能不能重现密钥。

2048 → 3072
RSA 不 initialize 时的默认模数位数:JDK 17 与 JDK 21 / 27
28.5–294.1 ms
RSA 2048 生成 30 次的最快与最慢(中位数 65.2 ms);EC P-256 为 0.12–0.25 ms
相同 vs 不同
用 setSeed(12345) 的 SHA1PRNG 与 DRBG 各生成两把 RSA 1024 密钥,模数是否相同

固定种子

实测 · 本机执行输出 
  SHA1PRNG:用 setSeed(12345) 的 SecureRandom 各生成一把 RSA 1024 密钥,两次的模数完全相同(密钥可重现):[88e453ac7d8e84fdc67b82c9, 88e453ac7d8e84fdc67b82c9]
  DRBG:用 setSeed(12345) 的 SecureRandom 各生成一把 RSA 1024 密钥,两次的模数不同:[801b409b5ada23633e8839c4, c017bb169cff4ac17c038a51]
  NativePRNG:用 setSeed(12345) 的 SecureRandom 各生成一把 RSA 1024 密钥,两次的模数不同:[9368ab1444a2ffc035dd3588, 8ac7ef1e04d9fb29d4ea3cb4]
  SHA1PRNG + setSeed(1):EC P-256 私钥相同 = true
  默认 new SecureRandom() 的算法 NativePRNG,提供者 SUN;KeyPairGenerator 不传 SecureRandom 时使用 JDK 内部的默认实例(与它相同类型)
  SHA1PRNG:先 setSeed(42) 再取字节 d50ac288b90ede2e;先取字节再 setSeed(42)(补充种子而不是替换)得到 986aadeb165af734(两者不同:setSeed 在第一次取字节之后只是追加熵)

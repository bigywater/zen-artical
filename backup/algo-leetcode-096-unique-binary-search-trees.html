LeetCode 96. 不同的二叉搜索树

给定整数 n，问用 1 到 n 这 n 个互不相同的数，能组成多少种结构不同的二叉搜索树。上一题（第 95 题）要把每一棵树都造出来，这一题只要数出个数，所以不需要真的建树。二叉搜索树的结构由"选谁当根"决定：如果选第 root 小的数当根，那么比它小的 root - 1 个数必须在左子树，比它大的 n - root 个数必须在右子树，左右两边互相独立，方案数相乘。用 dp[k] 表示 k 个结点能组成的树的个数，dp[k] 等于对 root 从 1 到 k 求 dp[root-1] × dp[k-root] 的和。这个数列就是卡特兰数。本文用真实运行验证它与卡特兰数公式一致，展示不带记忆化递归的调用次数，用 Java 展示 n = 20 时 32 位整数溢出，给出五种语言的实现，并把填表做成分步演示。

动态规划：五种语言的实现

dp[0] = 1（空树也算一种）。对 k 从 1 到 n，对 root 从 1 到 k：dp[k] += dp[root - 1] * dp[k - root]。返回 dp[n]。时间 O(n²)，空间 O(n)。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(n): dp = [0] * (n + 1) # dp[k]：k 个不同的数能组成多少种二叉搜索树 dp[0] = 1 # 0 个结点：只有一种（空树） for k in range(1, n + 1): for root in range(1, k + 1): # 选第 root 小的数当根：左子树有 root-1 个结点，右子树有 k-root 个 dp[k] += dp[root - 1] * dp[k - root] return dp[n]

耗时实测

n 分别为 100、300、1000、2000，每个规模取三次中最快的一次（Python 的整数不会溢出，所以答案会变成非常大的整数）：

真实实测 · 本机执行输出
n | 暴力解 | 本文解法
       100 |     0.005 ms | 0.362 ms
       300 |     0.019 ms | 5.032 ms
      1000 |     0.115 ms | 275.123 ms
      2000 |     0.432 ms | 4049.855 ms

在 Python 里，直接用公式（基准）比动态规划快得多：n = 2000 时 0.432ms 对 4049.9ms。原因有两个：公式是 C 实现的一次大整数运算；动态规划的 O(n²) 次乘加，在 n 大时每次都是对上千位大整数的运算，所以耗时比 n² 增长得更快（n 从 300 到 1000，耗时增长约 55 倍，n² 只有 11 倍）。这不影响本题的正确性，题目限制 n ≤ 19，动态规划远远够用；这里只是说明大整数的代价。

ArrayReflectNewInstanceDemo.java static <T> T[] createArray(Class<T> componentType, int size) { return (T[]) Array.newInstance(componentType, size); // 泛型方法内部无法直接 new T[size] }

真实结果证明 Array.newInstance() 能在运行时才知道元素类型(通过 Class 对象)的情况下,动态创建出数组——这正是系列前面 泛型擦除那篇提到的限制的标准解决方案:泛型方法内部由于类型参数 T 在运行时已经被擦除,编译器不允许写 new T[size],但可以通过传入一个显式的 Class<T> 参数,用反射绕过这个限制。

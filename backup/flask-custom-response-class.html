自定义 Response Class

想让所有响应都带一个头、让视图直接返回 dataclass 或 Pydantic 对象,该改哪里?自定义 Response 类能做到什么、做不到什么?这篇踩一遍坑,再给出能用的写法。

500
自定义 force_type 后视图返回模型对象仍然得到的状态码
2
真正起作用的扩展点:Response 子类(统一加头)与 Flask.make_response(处理模型对象)
X-Api-Version
本篇统一加到所有响应(含 404)的头

force_type 的调用时机

实测 · 本机执行输出 
  返回 str                → 200 | force_type 被调用:[]
  返回 dict               → 200 | force_type 被调用:[]
  返回 Response           → 200 | force_type 被调用:['Response']
  返回 werkzeug Response  → 200 | force_type 被调用:['Response']
  返回 WSGI callable      → 200 | force_type 被调用:['function']

AopContext 与 AopUtils:拿到原始对象

怎么从代理对象拿回原始对象?代理类上找不到注解怎么办?代理和目标 equals 吗?多个切面叠加是几层代理?这篇在 Spring Framework 7.0.9 上逐项验证。

4 个

null
CGLIB 代理类上直接 getAnnotation 目标类注解的结果(findAnnotation 能找到)
false
代理 equals 目标(JDK 与 CGLIB 都是)

拿回原始对象

实测 · 本机执行输出 
  JDK 代理:getClass() = $Proxy2;AopUtils.getTargetClass = JdkTarget;AopProxyUtils.ultimateTargetClass = JdkTarget;ClassUtils.getUserClass = $Proxy2
    ((Advised) proxy).getTargetSource().getTarget() = JdkTarget;proxy == target ? false;isAopProxy(target) = false
  CGLIB 代理:getClass() = CglibTarget·CGLIB;AopUtils.getTargetClass = CglibTarget;AopProxyUtils.ultimateTargetClass = CglibTarget;ClassUtils.getUserClass = CglibTarget
    ((Advised) proxy).getTargetSource().getTarget() = CglibTarget;proxy == target ? false;isAopProxy(target) = false
  两层代理:最外层 → getTarget() 得到 $Proxy2(还是个代理:true);AopProxyUtils.getSingletonTarget(最外层) = $Proxy2;ultimateTargetClass = JdkTarget;AopUtils.getTargetClass = $Proxy2
    getSingletonTarget 连续两次 → JdkTarget

getTargetClass、ultimateTargetClass、getTarget() 各有适用范围,多层代理要用 ultimate 系列。

找注解

实测 · 本机执行输出 
  CGLIB 代理 CglibTarget·CGLIB:pc.getAnnotation(Tag.class) = null;pc.isAnnotationPresent(Tag) = false
    AnnotationUtils.findAnnotation(pc, Tag.class) = @Tag(on-class);AnnotatedElementUtils.findMergedAnnotation = @Tag(on-class);getAnnotation(AopUtils.getTargetClass(p)) = @demo.Main.Tag("on-class")
  JDK 代理 $Proxy2:jc.getAnnotation(Tag.class) = null;findAnnotation(jc) = null;findAnnotation(AopUtils.getTargetClass(j)) = @Tag(on-class)

代理类上直接 getAnnotation 会漏掉类注解,要用 findAnnotation 或目标类。

身份比较

实测 · 本机执行输出 
  CGLIB 代理:p1.equals(p1) = true;p1.equals(target) = false;target.equals(p1) = false;p1.hashCode() == target.hashCode() ? false;p1.toString() 以 CglibTarget 开头?true
  JDK 代理:j1.equals(j1) = true;j1.equals(target) = false;j1.hashCode() == target.hashCode() ? false;HashSet 里放 target 再用 j1 查 contains = false

代理和目标不相等,混放在集合里会查不到。

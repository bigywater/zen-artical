Graal JIT:可编程编译器如何优化 Java

Graal 是用 Java 写成、可以替换 C2 的 JIT 编译器。这篇在同一个 JDK 上只切换编译器,量出它的逃逸分析、稳态吞吐、预热曲线和内存成本,并如实记录一个预期没有出现的优化。

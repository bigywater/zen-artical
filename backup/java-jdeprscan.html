jdeprscan:提前发现已弃用 API

升级 JDK 之前怎么知道自己的 jar 和依赖里有多少已废弃甚至即将移除的 API?javac 的警告看不到第三方 jar,jdeprscan 可以。这篇用它扫自己的类和三个老库,并看各个 release 的废弃清单有多大。

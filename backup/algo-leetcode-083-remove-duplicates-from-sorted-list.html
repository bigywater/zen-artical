LeetCode 83. 删除排序链表中的重复元素

给定一个升序链表，删除所有重复的元素，使每个元素只出现一次（重复的保留一个）。因为链表有序，重复的元素一定挨在一起，所以只需要比较相邻的两个结点：如果当前结点 cur 和它的下一个值相同，就把下一个结点摘掉（cur.next = cur.next.next）；不同才让 cur 前进。这里有一个很容易写错的细节：摘掉之后 cur 不能前进，因为新的下一个结点可能还是重复的。本文用真实数据展示这个错误会错多少，给出五种语言的实现，并把逐个摘除的过程做成分步演示。

陷阱：摘掉重复结点之后，cur 不能前进

把"摘掉重复结点"和"cur 前进"写成两个独立的步骤（先判断并摘除，再无条件前进），看起来也顺理成章。但如果一个值出现了三次或更多，cur 摘掉第一个重复之后已经前进到了下一个结点，剩下的重复就被漏掉了。下面是这种写法与 solve 的真实结果：

随机 20000 个链表：该写法出错的有 8767 个（43.8%）

[1, 1, 2] 和 [1, 1, 2, 3, 3] 两种写法碰巧一致（每个值只重复了一次）；但 [1, 1, 1] 得到 [1, 1]，[1, 1, 1, 2] 得到 [1, 1, 2]：三个 1 只去掉了一个。在随机的 20000 个链表里（重复值很多），这种写法出错的有 8767 个，占 43.8%。所以只用官方示例（每个值最多重复一次）测不出这个错误。

相邻比较：五种语言的实现

cur 从头结点出发。只要 cur 和 cur.next 都存在：如果两者值相同，摘掉下一个结点：cur.next = cur.next.next，cur 不动；否则 cur = cur.next。循环结束时链表末尾也处理完了，返回原来的头结点。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码class ListNode: def __init__(self, val=0, next=None): self.val = val self.next = next def delete_duplicates(head): cur = head while cur and cur.next: if cur.val == cur.next.val: cur.next = cur.next.next # 后一个结点重复：把它摘掉；cur 不动，因为新的后一个可能还是重复的 else: cur = cur.next # 后一个结点不同：cur 前进 return head

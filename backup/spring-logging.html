运行时改级别

实测 · 本机执行输出 
  初始:GET /actuator/loggers/demo.rt → 404 ;/log?n=demo.rt 输出 debug 行数 0
  POST /actuator/loggers/demo {"configuredLevel":"DEBUG"} → 204
  之后:GET /actuator/loggers/demo.rt → {"effectiveLevel":"DEBUG"};/log?n=demo.rt 输出 debug 行数 1(没有重启)
  POST {"configuredLevel":null} → 204;GET /actuator/loggers/demo → {"effectiveLevel":"INFO"};debug 行数 0
  对分组 web 发 POST /actuator/loggers/web {"configuredLevel":"TRACE"} → 204;GET /actuator/loggers/org.springframework.web → {"configuredLevel":"TRACE","effectiveLevel":"TRACE"}
  非法级别 LOUD → 400

POST /actuator/loggers/{名字},包括分组,立即生效,null 恢复。

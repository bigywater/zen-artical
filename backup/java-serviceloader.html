classpath 上的 SPI

实测 · 本机执行输出 
  ServiceLoader.load(...) 返回后,还没有迭代:没有任何构造器运行(惰性)
  先只看 providers 的类型(sl.stream().map(Provider::type)):[B, A, C]——仍然没有实例化
  第一次迭代(for-each):
    [B 的构造器运行]
    得到 B
    [A 的构造器运行]
    得到 A
    [C 的构造器运行]
    得到 C
  第二次迭代(缓存):
    没有再运行构造器,顺序 = [B, A, C]
  reload() 之后再迭代:
    [B 的构造器运行]
    得到 B
    [A 的构造器运行]
    得到 A
    [C 的构造器运行]
    得到 C
    [B 的构造器运行]
  findFirst() 只实例化第一个:
    得到 B

    [B 的构造器运行]
    B
  迭代时抛 ServiceConfigurationError: Plain not a subtype
  [只有带参构造器的类 NoDefault]
    [B 的构造器运行]
    B
  迭代时抛 ServiceConfigurationError: NoDefault Unable to get public no-arg constructor

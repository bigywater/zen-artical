Result 错误传播

? 让 Rust 的错误处理简洁,但每一个细节都有规则:什么函数里才能用、错误类型怎么转换、Option 与 Result 能不能混用、main 里出错会怎样。这篇每一条规则都用编译与运行结果验证。

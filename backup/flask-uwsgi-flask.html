uWSGI 与 Flask

uWSGI 怎么部署 Flask?默认参数有哪些坑?线程、预加载、超时各是什么行为?这篇用真实的 uwsgi 把每个参数的效果验证出来,包括一个和文档不一致的结果。

--callable
不写时 uWSGI 找 application 变量,找不到就让每个请求 500
--lazy-apps
让每个 worker 各自加载应用,避免 fork 共享导入时的资源
线程
这个版本不加 --enable-threads 线程也运行,与文档说法不同

预加载与 --lazy-apps

实测 · 本机执行输出 
  默认(master 加载后 fork)        看到 3 个 worker,TOKEN 有 1 个不同的值
  --lazy-apps                看到 3 个 worker,TOKEN 有 3 个不同的值

IGMPv2 与 IGMPv3:报文格式与源过滤

IGMPv3 比 v2 多了什么?“只接收某个源的组播”是怎么表达的?本机的套接字源过滤是真的吗,路由器知道吗?这篇手工构造各种 v2 / v3 报文用 tcpdump 和 scapy 一起解码,再用真实套接字测源过滤。

8 字节 / 16 字节

0 个 v3
本机加入 / 屏蔽 / 离开的过程中发出的 IGMPv3 报告个数:线上全是 v2(16 个报文)
只要别的源 → 没收到
IP_ADD_SOURCE_MEMBERSHIP 只要另一个源时,本机内核对来自本机地址的组播的过滤结果

v2 与 v3 的区别

实测 · 本机执行输出 
    v2 通用查询(最大响应 10 秒)                    IGMP 部分   8 字节,校验和 0xee9b(验算 通过),整个 IP 包 32 字节
    v3 通用查询                               IGMP 部分  12 字节,校验和 0xec1e(验算 通过),整个 IP 包 36 字节
    v3 组-源查询(2 个源)                        IGMP 部分  20 字节,校验和 0x7d42(验算 通过),整个 IP 包 44 字节
    v2 成员报告                               IGMP 部分   8 字节,校验和 0xcf9c(验算 通过),整个 IP 包 32 字节
    v3 报告(1 条记录:EXCLUDE 空 = 加入整个组)        IGMP 部分  16 字节,校验和 0xc19b(验算 通过),整个 IP 包 40 字节
    v3 报告(2 条记录:INCLUDE{S1,S2} + EXCLUDE{})IGMP 部分  32 字节,校验和 0x51bd(验算 通过),整个 IP 包 56 字节
  v2 查询的“最大响应时间”字段是 1 字节、单位 0.1 秒(最大 25.5 秒);v3 的 8 位字段 ≥ 128 时用浮点格式:例如要表示 200 秒 = 2000 个 0.1 秒,编码成 0xc0,解回来是 2048
  v1 / v2 / v3 查询的区分:IGMP 部分长度 = 8 且最大响应时间 = 0 → v1;长度 = 8 且 ≠ 0 → v2;长度 ≥ 12 → v3
  v3 报告发往 224.0.0.22(所有 IGMPv3 路由器),v2 报告发往被报告的组地址本身,v2 离开发往 224.0.0.2

v2 的查询和报告都是 8 字节、针对单个组;v3 报告可以带多条记录,每条记录有类型和源地址列表;v3 查询能带源列表,长度 ≥ 12 字节。

记录类型

实测 · 本机执行输出 
    IP_ADD_MEMBERSHIP(任意源,加入)               → v3 报告里的记录:状态变化 CHANGE_TO_EXCLUDE{}(= 接收任何源)
    IP_DROP_MEMBERSHIP(离开)                  → v3 报告里的记录:状态变化 CHANGE_TO_INCLUDE{}(= 不接收任何源 = 离开)
    IP_ADD_SOURCE_MEMBERSHIP(加入时只要某个源)      → v3 报告里的记录:状态变化 CHANGE_TO_INCLUDE{S}
    再加一个源 S2                                → v3 报告里的记录:ALLOW_NEW_SOURCES{S2}
    IP_BLOCK_SOURCE(任意源模式下屏蔽 S)             → v3 报告里的记录:BLOCK_OLD_SOURCES{S} 或 CHANGE_TO_EXCLUDE{S}

v3 报告用 MODE_IS_* 报告当前状态,用 CHANGE_TO_* 和 ALLOW / BLOCK 报告变化,没有专门的 Leave。这些映射没有在线上验证,因为本机只发 v2。

源过滤

实测 · 本机执行输出 
  每种过滤方式用独立的套接字、独立的端口依次测试。发送方源地址 = 本机 en0 地址,发一个数据报到该组;结果:
    不过滤(任意源):收到
    只要本机地址这个源:收到
    只要另一个源(198.51.100.7):没收到
    任意源加入后屏蔽本机地址这个源:收到
    任意源加入后屏蔽另一个源:收到
  这些加入 / 屏蔽 / 离开的过程中线上的 IGMP 报文共 16 个,类型分布:0x16 × 11;0x17 × 5(0x16 = v2 报告,0x17 = v2 离开,0x22 = v3 报告)
  这个网段上的查询者是 v2(见上一篇),本机对它按 v2 说话:v2 报文里没有“源”的概念,过滤信息只存在于本机内核里,并没有告诉路由器

本机内核真的会按源地址过滤(只要别的源就收不到);屏蔽自己这个源的实验没有生效,原因没查。因为线上是 v2,路由器并不知道本机的源过滤。

编译器插件:把额外检查接入 Java 构建

想在编译期强制团队约定,又不想写注解处理器?javac 的 -Xplugin 可以让你直接访问语法树与类型信息。这篇写一个真实的小插件,看它在命令行与 Maven 里怎么被加载、怎么报告问题、怎么让构建失败。

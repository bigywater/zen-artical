常量、静态变量与 const

const、static 与 static mut 常被混在一起讲。这篇逐个验证:它们在内存里的位置,const fn 能把计算提前到编译期的证据,static mut 为什么需要 unsafe、2024 edition 又加了什么限制,以及安全的可变全局应该怎么写。

安全的可变全局

实测 · 本机执行输出 
  源码:
      1 | use std::sync::atomic::{AtomicUsize, Ordering};
      2 | use std::thread;
      3 | static COUNTER: AtomicUsize = AtomicUsize::new(0);
      4 | fn main() {
      5 |     let hs: Vec<_> = (0..4).map(|_| thread::spawn(|| { for _ in 0..1000 { COUNTER.fetch_add(1, Ordering::Relaxed); } })).collect();
      6 |     for h in hs { h.join().unwrap(); }
      7 |     println!("4 个线程各加 1000 次,COUNTER = {}", COUNTER.load(Ordering::Relaxed));
      8 | }
  编译:成功
  运行(退出码 0):

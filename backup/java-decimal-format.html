DecimalFormat:数字格式化的 Locale 与线程安全

数字格式化看起来简单,却同时牵扯 Locale、舍入、解析宽松度和线程安全。这篇逐项实测,尤其是共用一个 DecimalFormat 时哪些操作出错、哪些没有。

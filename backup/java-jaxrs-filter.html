JAX-RS Filter:在 HTTP 资源前后插入处理

JAX-RS 过滤器是在 HTTP 资源前后插入处理的标准方式。这篇用一个真实的 Jersey 服务,把请求与响应链的顺序、PreMatching、abortWith、异常映射、名字绑定和请求体读取这些容易混淆的行为逐个量出来。

升序 vs 降序
请求过滤器与响应过滤器按 @Priority 的执行顺序(100 → 400 与 300 → 100 → 10)
403 / 500
abortWith 与过滤器抛异常的 HTTP 状态;两种情况响应过滤器都照常运行
0 字节
请求过滤器读取了请求体但没放回时,资源方法收到的 body 长度(放回之后是 11)

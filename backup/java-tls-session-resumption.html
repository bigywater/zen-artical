复用的条件

实测 · 本机执行输出 
  基线(TLS 默认协商出 TLSv1.3):第 2 次与第 1 次同一个会话 = true
  同一个客户端 SSLContext,改用 "localhost" 连接同一个端口:同一个会话 = false(客户端按 主机名:端口 缓存会话)
  再用 "127.0.0.1" 连接:同一个会话 = true
  另一个客户端 SSLContext(各自有自己的会话缓存)连同一个服务器:与第 1 个客户端的会话相同 = false
  客户端会话缓存:getSessionCacheSize = 20480(0 = 不限),getSessionTimeout = 86400 秒;服务器端 getSessionTimeout = 86400 秒,getSessionCacheSize = 20480
  对会话调用 invalidate() 之后再连接:与之前同一个会话 = false(创建了新会话)

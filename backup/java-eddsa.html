EdDSA:现代椭圆曲线签名

Ed25519 常被当作 ECDSA 和 RSA 的现代替代。这篇在 JDK 21 上量出它的大小、确定性、与 RFC 8032 和 OpenSSL 的互通、验证边界,以及真实的性能数字——结果里有一条与常见印象相反。

1 vs 20
同一私钥同一消息签 20 次,Ed25519 与 ECDSA P-256 的不同签名个数
逐字节相同
Java 的 Ed25519 签名与 RFC 8032 测试向量 1 的签名、与 OpenSSL 签名的比较结果
422 vs 120 µs
JDK 21 上 Ed25519 与 ECDSA P-256 的单次签名耗时

大小与 API

实测 · 本机执行输出 
  Ed25519:算法 EdDSA,公钥 44 字节(X.509),私钥 48 字节(PKCS#8),签名 64 字节,公钥类型 EdECPublicKey
  Ed448:公钥 69 字节,私钥 73 字节,签名 114 字节
  ECDSA P-256:公钥 91 字节,私钥 67 字节,签名(DER)70 字节(长度随 r、s 变化,常见 70–72)
  RSA 2048:公钥 294 字节,私钥 1217 字节,签名 256 字节
  Ed25519 initialize(256):InvalidParameterException:Unsupported size: 256
  Signature.getInstance("EdDSA") 的提供者 SunEC,Ed25519 的提供者 SunEC

  同一把私钥、同一条消息各签 20 次,不同的签名个数:Ed25519 1,ECDSA P-256 20,RSA PKCS#1 v1.5 1,RSASSA-PSS 20

RFC 8032 与 OpenSSL

实测 · 本机执行输出 
  RFC 8032 测试向量 1(种子 9d61b19d…,空消息):Java 的签名与 RFC 给出的签名完全相同 = true(e5564300c360ac729086e2cc806e828a…)
  EdECPrivateKey.getBytes() 是 32 字节(就是 32 字节种子)= true
  已把 Java 生成的密钥和签名写到文件(公钥 X.509 DER、私钥 PKCS#8 DER、java.sig)
  openssl 版本:OpenSSL 4.0.3 29 Sep 2026 (Library: OpenSSL 4.0.3 29 Sep 2026)
  openssl 验证 Java 生成的签名:Signature Verified Successfully
  openssl 用 Java 的私钥签名:退出码 0,签名 64 字节;与 Java 的签名逐字节相同 = True
  Java 验证 openssl 生成的签名:true

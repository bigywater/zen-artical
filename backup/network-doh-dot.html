DoT 与 DoH:加密 DNS 与它们的代价

DNS 默认是明文的,路径上的任何设备都能看到你查了什么,也能抢先给你一个假答案。DoT 和 DoH 把 DNS 放进 TLS 里。这篇测它到底挡住了什么、没挡住什么、新建一次连接要多花多少,也记录了在这个网络里主流的海外加密 DNS 根本连不上。

5 / 5 超时
五个海外公共解析器 DoT 端点(Cloudflare ×2、Google、Quad9、AdGuard)中 TCP 连接超时的个数;阿里 223.5.5.5 连得上
80 → 8.6 ms
DoT 新建连接与复用连接的耗时中位数(UDP 53 为 11.4 ms)
2 包 → 20 包

  UDP 53 把名字原样暴露给路径上的任何设备;DoT / DoH 的名字被加密,但目标 IP、端口、TLS 的 SNI(服务器名)、包的大小和时间仍然可见

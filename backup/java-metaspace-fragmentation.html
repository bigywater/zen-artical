元空间碎片:类元数据为什么不只看容量

看元空间别只盯着 used:capacity、committed、free chunks 是不同的账。这篇用 jcmd VM.metaspace 与 MemoryPoolMXBean 同时读数,把加载器全部/部分丢弃后的变化量出来。

106.92 → 3.82 MB
300 个加载器全部丢弃并 GC 后 JDK 21 的 committed(jcmd Both 行)
78.81 vs 55.50 MB
同样丢弃一半加载器,交错丢弃与丢弃前一半之后虚拟空间的 committed
105472 KB
JDK 17 上 MetaspaceReclaimPolicy=none 时丢弃后 committed 仍然没降

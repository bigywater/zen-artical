自然顺序 与 Collator

实测 · 本机执行输出 
  原始: [zebra, Apple, apple, banana, Äpfel, éclair, eclair, Zoo, Eagle]
  String 自然顺序(按 UTF-16 码元):   [Apple, Eagle, Zoo, apple, banana, eclair, zebra, Äpfel, éclair]
  String.CASE_INSENSITIVE_ORDER:      [Apple, apple, banana, Eagle, eclair, zebra, Zoo, Äpfel, éclair]
  Collator(Locale.ENGLISH):           [Äpfel, apple, Apple, banana, Eagle, eclair, éclair, zebra, Zoo]
  Collator(Locale.GERMAN):            [Äpfel, apple, Apple, banana, Eagle, eclair, éclair, zebra, Zoo]
  瑞典语对比 [zebra, å, ä, ö, a, z]:
    Locale.ENGLISH: [a, å, ä, ö, z, zebra]
    Locale(sv):     [a, z, zebra, å, ä, ö]

strength 与 decomposition

实测 · 本机执行输出 
  compare("abc", "ABC"): PRIMARY=0 SECONDARY=0 TERTIARY=-1 IDENTICAL=-1
  compare("abc", "abç"): PRIMARY=0 SECONDARY=-1 TERTIARY=-1 IDENTICAL=-1
  compare("abc", "abc"): PRIMARY=0 SECONDARY=0 TERTIARY=0 IDENTICAL=0
  compare("résumé", "resume"): PRIMARY=0 SECONDARY=1 TERTIARY=1 IDENTICAL=1
  compare("é", "é"): PRIMARY=0 SECONDARY=0 TERTIARY=0 IDENTICAL=-1
  默认 strength = 2(TERTIARY=2),默认 decomposition = 0(NO_DECOMPOSITION=0,CANONICAL_DECOMPOSITION=1)
  IDENTICAL + NO_DECOMPOSITION:compare("e\u0301", "\u00e9") = -1
  IDENTICAL + CANONICAL_DECOMPOSITION:compare("e\u0301", "\u00e9") = 0
  TERTIARY + NO_DECOMPOSITION:compare("e\u0301", "\u00e9") = 0;两者的 equals = false

性能与自定义规则

实测 · 本机执行输出 
  20000 个随机字符串,Locale.GERMAN:Collator.compare 直接排序中位 97 ms;先生成 CollationKey 再排序(含生成)中位 23 ms;String 自然顺序中位 4 ms
  两种方式排序结果一致:true
  CollationKey("Äpfel").toByteArray() 长度 = 36(源串 5 个字符)
  自定义规则让 ch 排在 c 之后(捷克语风格,在 c 后加 ch),排序 [cista, chata, dobry, cesta, hrad, ciste]:
    默认 ENGLISH: [cesta, chata, cista, ciste, dobry, hrad]
    自定义规则:   [cesta, cista, ciste, chata, dobry, hrad]
  RuleBasedCollator.getRules() 长度(英语默认)= 850 个字符

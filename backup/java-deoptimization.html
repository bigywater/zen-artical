Deoptimization:优化假设失效后 JVM 如何退回解释执行

JIT 会做乐观的假设:这个调用点只有一种类型、这个分支不会走到。假设被打破时 JVM 退回解释器重新来过,这就是 deoptimization。这篇用真实的基准和 deopt 日志看三种典型情况:类型污染、冷分支变热、数组越界。

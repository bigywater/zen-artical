Template Interpreter:解释器如何执行字节码

解释器不是一个巨大的 switch,HotSpot 是在启动时为每个字节码生成一小段机器码。这篇把这些机器码打印出来,反汇编一个,再量解释执行有多慢、什么时候被编译。

JShell:用交互式会话验证 Java 想法

JShell 让你不写类、不写 main 就能验证一个想法。它怎么处理前向引用、重新定义、错误和异常?怎么用它试第三方库?它的 API 能做什么?这篇用 jshell 命令行与 jdk.jshell API 逐项真实运行。

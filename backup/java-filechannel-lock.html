FileChannel.lock:跨进程文件锁的边界

“用文件锁做跨进程互斥”看上去很简单。这篇用两个真实的 JVM 进程量出它的规则和边界:阻塞与非阻塞、共享与区域、同 JVM 与跨进程的差别,以及几个会让两个进程同时进入临界区的陷阱。

1934 ms
A 持有独占锁 2 秒时,B 的 lock() 等待的时间(tryLock 立即返回 null)
isValid = true,但锁已丢
同一进程里关闭同一个文件的另一个通道之后,另一个进程的 tryLock 成功了(macOS)
2 个持有者
锁文件被删除再重建后,A 与 B 都以为自己持有独占锁

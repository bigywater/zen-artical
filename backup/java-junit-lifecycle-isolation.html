JUnit 生命周期隔离

测试是否互相影响,往往取决于生命周期、顺序和并行这几个开关。这篇用最小的测试类把每个开关跑出来,看清隔离到底隔离了什么、没隔离什么。

每次一个新实例
JUnit Jupiter 默认(PER_METHOD)对每个测试方法与每次参数化 / 重复调用都新建测试类实例
319695 / 600000
并行 concurrent 下 3 个测试各 20 万次非原子 ++ 之后静态计数的值,3 个测试仍然全部通过
Random + PER_CLASS
6 个随机种子下共享 cart 的 3 个测试,每个种子都至少有 1 个失败(PER_METHOD 全部通过)

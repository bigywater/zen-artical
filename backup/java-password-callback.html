PasswordCallback:认证过程中如何请求密码

JAAS 把「向谁要口令、要什么」拆成 LoginModule 与 CallbackHandler。这篇用真实运行的模块,逐个看回调对象怎么保存口令、多个模块怎么各自提问、出错时是什么样子。

副本
PasswordCallback.setPassword / getPassword 都是副本,clearPassword 只清内部那一份
字节流里有口令
序列化一个设置了口令的 PasswordCallback 后能在字节流里找到口令(字段不是 transient)
2 次 vs 1 次
两个 required 模块各向 handler 要一次口令;A 存口令、B 用 useFirstPass 时只要一次

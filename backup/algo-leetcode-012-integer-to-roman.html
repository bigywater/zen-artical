LeetCode 12. 整数转罗马数字

把 1 到 3999 的整数转换成罗马数字。罗马数字用 I V X L C D M 七个符号表示 1、5、10、50、100、500、1000，通常大的符号写在左边、做加法；但有六种"减法组合"——IV（4）、IX（9）、XL（40）、XC（90）、CD（400）、CM（900）——小的符号写在大的符号左边，表示大减小。这道题的关键是把这六个减法组合也放进价值表里，然后从大到小贪心：能减就减。因为输入范围只有 3999 个整数，本文对全部输入做了穷举验证，而不是只挑几个例子。

陷阱：只用七个基本符号做加法

最容易想到的做法是只用七个符号，从大到小不停地减。这样得到的结果数值上是对的，但不是标准写法，因为它没有使用减法组合。下面是这种写法和标准写法在几个数上的真实对比：

真实实测 · 本机执行输出
# 只用 7 个基本符号做加法（没有 CM、CD、XC、XL、IX、IV 这些减法组合）
   4: 只做加法 -> IIII               solve -> IV           是否相同：False
   9: 只做加法 -> VIIII              solve -> IX           是否相同：False
  58: 只做加法 -> LVIII              solve -> LVIII        是否相同：True
1994: 只做加法 -> MDCCCCLXXXXIIII    solve -> MCMXCIV      是否相同：False
3999: 只做加法 -> MMMDCCCCLXXXXVIIII solve -> MMMCMXCIX    是否相同：False

4 应该写 IV，只做加法会写成 IIII；1994 应该是 MCMXCIV，只做加法是 MDCCCCLXXXXIIII。58 这类不含减法组合的数，两种写法碰巧相同，所以只测这样的例子发现不了问题。把六个减法组合加进从大到小的价值表里就能解决。

贪心：五种语言的实现

价值表是 13 项，从 1000 到 1，其中包含六个减法组合。从前往后依次处理：只要剩余的数不小于当前价值，就写出对应符号并减去这个价值。因为每一档都用尽了才会往下走，结果一定是标准写法。五种语言都是真实编译运行的。

Python · 解法代码def solve(num): table = [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"), (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")] out = [] for value, symbol in table: # 从大到小，能减就减：贪心 while num >= value: out.append(symbol) num -= value return "".join(out)

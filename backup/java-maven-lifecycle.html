Maven 生命周期:阶段与插件目标如何组合

Maven 的生命周期由阶段构成,而阶段本身不做事,插件目标绑定到阶段上才执行。这篇用一个真实的 jar 项目验证:每个阶段累加执行哪些目标、绑定顺序、直接调用目标的后果、两个跳过测试的开关以及失败时的行为。

  mvn validate:rc=0,执行 0 个目标:(无)
  mvn compile:rc=0,执行 2 个目标:resources:resources → compiler:compile

  mvn package:rc=0,执行 6 个目标:resources:resources → compiler:compile → resources:testResources → compiler:testCompile → surefire:test → jar:jar
  mvn verify:rc=0,执行 6 个目标:resources:resources → compiler:compile → resources:testResources → compiler:testCompile → surefire:test → jar:jar
  mvn install:rc=0,执行 7 个目标:resources:resources → compiler:compile → resources:testResources → compiler:testCompile → surefire:test → jar:jar → install:install

  先 mvn compile 再 mvn jar:jar:jar 条目数 9,其中 .class 1 个,a.txt 1 个
  mvn compile surefire:test(阶段与目标混用):执行 3 个目标:resources:resources → compiler:compile → surefire:test

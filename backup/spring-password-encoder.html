DelegatingPasswordEncoder

实测 · 本机执行输出 
  encode("secret") = {bcrypt}$2a$10$ABga77euJ266Yktz8GEDau5UGkfb7I/1i9lzBHsM3x0KUKNnWUKaW
  matches 带前缀的各种哈希(同一个明文 secret):
    {noop} → matches=true,哈希长度 12
    {bcrypt} → matches=true,哈希长度 68
    {pbkdf2@SpringSecurity_v5_8} → matches=true,哈希长度 124
    {scrypt@SpringSecurity_v5_8} → matches=true,哈希长度 105
    {argon2@SpringSecurity_v5_8} → matches=true,哈希长度 125
  没有前缀的哈希(例如直接从旧库里读出来的 BCrypt):
    抛 IllegalArgumentException:Given that there is no default password encoder configured, each password must have a password encoding prefix. Please either prefix this password with '{noop}' or set a default password encoder in `DelegatingPasswordEncoder`.
    setDefaultPasswordEncoderForMatches(BCrypt) 之后 matches → true
  upgradeEncoding(是否需要用新参数重新编码):
    {bcrypt} strength 4 → true;{bcrypt} strength 10(默认)→ false;{noop} → true;{bcrypt} strength 12 → false

前缀选算法;无前缀要设默认编码器;upgradeEncoding 用来升级旧哈希。

边界

实测 · 本机执行输出 
  只在第 72 个字节之后不同的两个密码:matches(72 字节原文, 哈希)=true,matches(86 字节、前 72 字节相同, 同一个哈希)=true
  encode(73 字节的密码):抛 IllegalArgumentException:password cannot be more than 72 bytes
  matches(null, 哈希) 成功
  matches("", 空密码的哈希):false
  matches("secret", "not-a-hash"):false

encode 拒绝超过 72 字节,matches 会忽略 72 字节之后;空密码和乱格式哈希不抛异常。

算法对比

实测 · 本机执行输出 
  BCrypt 默认(strength 10):encode 中位 67.8 ms,matches 中位 67.6 ms,哈希长度 60
  Pbkdf2 defaultsForSpringSecurity_v5_8:encode 中位 38.8 ms,matches 中位 38.9 ms,哈希长度 96
  SCrypt defaultsForSpringSecurity_v5_8:encode 中位 112.5 ms,matches 中位 106.3 ms,哈希长度 77
  Argon2 defaultsForSpringSecurity_v5_8:encode 中位 16.6 ms,matches 中位 15.5 ms,哈希长度 97

四种默认参数都在几十毫秒量级,但强度不能直接比较。

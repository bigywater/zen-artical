开关的优先关系

实测 · 本机执行输出 
  flask run(无参数)                     → 调试器页面: False
  flask run --debug                  → 调试器页面: True
  FLASK_DEBUG=1 flask run            → 调试器页面: True
  FLASK_DEBUG=0 flask run --debug    → 调试器页面: True

调试器的 PIN 保护与交互式控制台本篇没有验证,也没有尝试使用控制台。

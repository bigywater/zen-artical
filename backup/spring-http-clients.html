选了什么底层

实测 · 本机执行输出 
  ClientHttpRequestFactoryBuilder.detect() 建出的工厂 = JdkClientHttpRequestFactory
  RestTemplateBuilder.build() 的工厂 = JdkClientHttpRequestFactory
  new RestTemplate() 的工厂 = SimpleClientHttpRequestFactory
  spring.http.clients.imperative.factory=simple 时:
  ClientHttpRequestFactoryBuilder.detect() 建出的工厂 = JdkClientHttpRequestFactory
  RestTemplateBuilder.build() 的工厂 = SimpleClientHttpsRequestFactory
  new RestTemplate() 的工厂 = SimpleClientHttpRequestFactory
  spring.http.clients.imperative.factory=simple 时 RestClient 的请求头:
  rc-boot 服务端看到的请求头 = {"User-Agent": "Java/21.0.12.1", "Accept": "*/*", "Connection": "keep-alive"}

有 Boot 配置时没有 Apache 就用 JDK HttpClient;new RestTemplate() 用 HttpURLConnection。

连接超时

实测 · 本机执行输出 
  spring.http.clients.connect-timeout=300ms:
  RestClient 连 10.255.255.1:81 异常 ResourceAccessException ← HttpConnectTimeoutException ← ConnectException,用时 331 ms
  不配置连接超时(最多等 20 秒):
  20 秒内没有返回,测试程序被强行终止(rc=-9)

不配置时连不可达地址会挂很久。

状态码

实测 · 本机执行输出 
  retrieve().body(String) /s/200 → 返回 'body-of-200'
  retrieve().body(String) /s/204 → 返回 null
  retrieve().body(String) /s/404 → 抛 NotFound,状态 404,body='body-of-404'
  retrieve().body(String) /s/500 → 抛 InternalServerError,状态 500,body='body-of-500'
  exchange() /s/404 → 不抛,拿到 '404 body-of-404'
  onStatus 自定义 /s/404 → 抛 IllegalStateException: 自定义 4xx 处理:404 NOT_FOUND
  onStatus 吞掉 500 → toBodilessEntity 状态 500
  RestTemplate /s/404 → 抛 NotFound

4xx/5xx 默认抛异常,exchange 与 onStatus 可改。

HTTP Interface

实测 · 本机执行输出 
  api.echo(x=a b, h=H1) → x=a b,X-Test=H1
  api.status(200) → body-of-200
  api.statusEntity(404) 通过 ResponseEntity 接 → 仍然会抛?
  api.statusEntity(404) 抛 NotFound
  api.status(500) 抛 InternalServerError 状态 500

声明式接口,异常行为与 RestClient 一致。

重定向

实测 · 本机执行输出 
  默认:
  RestClient GET /redirect → 状态 200 body='ok'
  RestTemplate(Boot 构建)GET /redirect → 'ok'
  new RestTemplate() GET /redirect → 'ok'
  spring.http.clients.redirects=dont-follow:
  RestClient GET /redirect → 状态 302 body='null'
  RestTemplate(Boot 构建)GET /redirect → 'null'
  new RestTemplate() GET /redirect → 'ok'

默认跟随;dont-follow 只对 Boot 构建的客户端生效。

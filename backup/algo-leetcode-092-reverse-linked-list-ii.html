LeetCode 92. 反转链表 II

给定一个链表和两个位置 left、right（从 1 开始计数，left ≤ right），只翻转从第 left 个到第 right 个结点这一段，其余部分保持原样。这是"反转链表"的区间版本。有一个很干净的做法叫头插法：用哑结点 dummy 处理 left 等于 1 的情形；让 prev 走到第 left 个结点的前一个；cur 是原来的第 left 个结点，它在整个过程中始终不动，反复把 cur 后面的那个结点摘下来，插到 prev 的后面（也就是区间的最前面），重复 right - left 次。这样只需要一遍扫描、没有额外的空间。本文用真实数据展示没有哑结点的写法会错在哪里，给出五种语言的实现，并把头插的过程做成分步演示。

陷阱：left = 1 时，头结点会变

翻转的区间包含头结点时（left = 1），翻转之后新的头结点变成了原来的第 right 个结点。如果没有哑结点，很容易写成"总是返回原来的头结点"，而原来的头结点现在已经被翻转到了区间的末尾，返回它得到的是一条缩短的链表。下面是这种写法的真实结果：

[1, 2, 3, 4, 5], left=1, right=3: 该写法 -> [1, 4, 5]    solve -> [3, 2, 1, 4, 5]
[1, 2], left=1, right=2: 该写法 -> [1]    solve -> [2, 1]
[1, 2, 3], left=1, right=3: 该写法 -> [1]    solve -> [3, 2, 1]
随机 20000 组：该写法出错的有 2807 组（14.0%）

[1, 2, 3, 4, 5] 翻转第 2 到 4 个时（不包含头结点），两种写法一致；翻转第 1 到 3 个时，错误写法返回 [1, 4, 5]，正确答案是 [3, 2, 1, 4, 5]；[1, 2] 翻转整条链，错误写法只剩 [1]。在随机的 20000 组数据里（left 在 1 到长度之间随机），错误写法出错的有 2807 组，占 14.0%，几乎全部集中在 left = 1 的情形。哑结点让"区间前面的结点"永远存在，返回 dummy.next 就总是正确的新头结点。

头插法：五种语言的实现

dummy 指向头结点，prev 从 dummy 出发走 left - 1 步，到第 left 个结点的前一个。cur = prev.next，也就是原来的第 left 个结点。然后重复 right - left 次：取 nxt = cur.next（cur 后面的结点），把它从原位置摘下（cur.next = nxt.next），插到 prev 后面（nxt.next = prev.next; prev.next = nxt）。每次循环，区间最前面多了一个结点，cur 被越挤越靠后，最后到了区间末尾，并且它的 next 已经自然指向了 right 后面的第一个结点。返回 dummy.next。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码class ListNode: def __init__(self, val=0, next=None): self.val = val self.next = next def reverse_between(head, left, right): dummy = ListNode(0, head) # 哑结点：left = 1 时头结点也要被翻转 prev = dummy for _ in range(left - 1): # prev 走到「第 left 个结点的前一个」 prev = prev.next cur = prev.next # cur 始终是原来的第 left 个结点，它会慢慢被"挤"到区间末尾 for _ in range(right - left): # 头插法：每次把 cur 后面的结点摘下来，插到区间的最前面（prev 之后） nxt = cur.next cur.next = nxt.next nxt.next = prev.next prev.next = nxt return dummy.next

Java · 解法代码class ListNode { int val; ListNode next; ListNode(int v) { val = v; } } class Solution { public ListNode reverseBetween(ListNode head, int left, int right) { ListNode dummy = new ListNode(0); // 哑结点：left = 1 时头结点也要被翻转 dummy.next = head; ListNode prev = dummy; for (int i = 0; i < left - 1; i++) prev = prev.next; // prev 走到「第 left 个结点的前一个」 ListNode cur = prev.next; // cur 始终是原来的第 left 个结点，它会慢慢被"挤"到区间末尾 for (int i = 0; i < right - left; i++) { // 头插法：每次把 cur 后面的结点摘下来，插到区间的最前面（prev 之后） ListNode nxt = cur.next; cur.next = nxt.next; nxt.next = prev.next; prev.next = nxt; } return dummy.next; } }

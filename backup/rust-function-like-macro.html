Function-like Macro

函数式过程宏能在编译期运行任意 Rust 代码:算常量、解析自定义语法、读文件。但它也有陷阱:cargo 不知道宏读过什么文件。这篇三种用法都真实跑通,并复现了那个「改了文件却没生效」的坑。

编译期读文件的陷阱

实测 · 本机执行输出 
  build 后运行: 版本 = "1.0"
  把 version.txt 改成 2.0 后 cargo build 输出: ['Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.01s']
  运行: 版本 = "1.0" ← 仍是旧值(宏没有重新运行)
  改动 main.rs(加一个换行)再 build 后运行: 版本 = "2.0"

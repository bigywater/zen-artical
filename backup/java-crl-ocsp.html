CRL 与 OCSP:证书撤销状态

证书吊销检查的结果不只是「好」与「坏」,还有「查不到」。这篇在本机搭起真实的 CRL 与 OCSP 服务,把各种选项在服务正常、过期、停掉时的行为逐个跑出来。

SOFT_FAIL 放行
响应器停掉时,SOFT_FAIL 让已吊销的 leaf2 也通过验证(记录 1 条软失败)
0 → 1 次
默认 PKIXParameters 不加 enableCRLDP 时 CRL 服务器收到的请求(0),与加上之后(1)
268 → 707986 字节
2 条与 20002 条吊销记录的 CRL 大小

    本文用到的工具与边界

    • 本机 macOS 27 arm64 / OpenJDK(Temurin 17.0.20、Homebrew 21.0.12 与 27,每篇注明实际用的版本);用 javac 编译、java 直接运行,需要第三方库时用 Maven 解析依赖;计时用 System.nanoTime,数字每次运行会有小幅抖动。JDK 21.0.12;证书与 CRL 由 OpenSSL 3.6.4 现场生成(EC P-256),CRL 服务器是 python3 http.server(127.0.0.1:9710),OCSP 响应器是 openssl ocsp -index(127.0.0.1:9711),实验结束后已停止;CRL 与 OCSP 的耗时包含 JVM 首次类加载,不应当作网络延迟

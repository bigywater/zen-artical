request.meta 里的特殊键

request.meta 是 Scrapy 里最杂的一个字典:既有你写给 Scrapy 的开关,也有 Scrapy 写给你的记录。这篇从源码里把所有键列出来分类,再把前面没单独验证过的几个开关一一实测。

输入键(dont_redirect、download_timeout、proxy 等)改变这个请求怎么被处理;输出键(depth、redirect_*、retry_times、download_latency 等)是中间件写给你的记录。下划线开头的是内部键,别碰。

请求级的覆盖

实测 · 本机执行输出 
  /big [('download_maxsize', 1000)]                           → errback DownloadCancelledError
  /big []                                                     → 回调 status=200 5000 字节
  /e404 [('handle_httpstatus_all', True)]                     → 回调 status=404 1 字节
  /e404 []                                                    → errback HttpError
  /e500 [('handle_httpstatus_list', [500])]                   → 回调 status=500 1 字节
  /e503 [('handle_httpstatus_list', [500])]                   → errback HttpError
  /slow [('download_timeout', 0.3)]                           → errback DownloadTimeoutError
  /slow []                                                    → 回调 status=200 18 字节

download_timeout、download_maxsize、handle_httpstatus_all/list 可以只对一个请求覆盖全局设置。

出口地址

实测 · 本机执行输出 
  不设                                  → [{'who': 'callback'}];服务器看到的客户端地址 127.0.0.1
  ('127.0.0.1', 0)                    → [{'who': 'callback'}];服务器看到的客户端地址 127.0.0.1
  ('10.255.255.1', 0)(本机没有这个地址)       → [{'who': 'errback', 'exc': 'ConnectBindError', 'msg': "Couldn't bind: 49: Can't assign requested address."}];服务器看到的客户端地址 (没收到)

bindaddress 指定本地出口,本机没有的地址会得到 ConnectBindError。

Referer 策略

实测 · 本机执行输出 
  None                              → 目标请求的 Referer = http://主机/link?q=1
  no-referrer                       → 目标请求的 Referer = (无)
  origin                            → 目标请求的 Referer = http://主机/
  same-origin                       → 目标请求的 Referer = http://主机/link?q=1
  strict-origin-when-cross-origin   → 目标请求的 Referer = http://主机/link?q=1
  unsafe-url                        → 目标请求的 Referer = http://主机/link?q=1

referrer_policy 决定跟随链接时发什么 Referer:不发、只发源、或完整 URL。

认证

实测 · 本机执行输出 
  meta http_user/http_pass:/a → alice:s3cret;加 http_auth_domain=localhost(请求在 127.0.0.1)/b → (无);请求自带 Authorization 头 /c → ['Bearer own']
  只设 HTTPAUTH_USER / HTTPAUTH_PASS(没设 HTTPAUTH_DOMAIN):退出码≠0?是;服务器收到 0 个请求;错误:ValueError: HTTPAUTH_DOMAIN must be set when HTTPAUTH_USER or HTTPAUTH_PASS is configured. Set it to a domain (e.g. 'example.com') to restrict credent
  HTTPAUTH_DOMAIN=127.0.0.1(不带端口,请求 URL 带端口):/a → (无)
  HTTPAUTH_DOMAIN=localhost(请求在 127.0.0.1):/a → (无)
  HTTPAUTH_DOMAIN=127.0.0.1:<端口>(域名带上端口):/a → bob:pw  ← 匹配用的是 URL 的 netloc(含端口),所以 URL 里有端口时域名也得带端口
  meta http_auth_domain=127.0.0.1:<端口>:/b → alice:pw

http_user / http_pass 给单个请求加 Basic 认证,设置级的认证必须配域名;域名匹配的是含端口的 netloc。

经过重定向、重试等中间件后,response.meta 里会多出一批输出键;它们不会被 response.follow 继承。

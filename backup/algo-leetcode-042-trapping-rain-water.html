LeetCode 42. 接雨水

给定一排宽度为 1 的柱子的高度，计算下雨之后能接多少单位的雨水。每一格能存的水，等于它左边最高的柱子和右边最高的柱子里较矮的那个，减去它自己的高度（不足则为 0）。直接按定义算，每一格要扫描左右两边，是 O(n²)。这道题是经典的一题多解：前后缀最大值数组、单调栈、双指针。本文给出双指针的五种语言实现，并在 Python 里验证四种做法的答案一致、比较它们的耗时，再把双指针的移动做成分步演示。

双指针：五种语言的实现

思路：两个指针 l、r 从两端往中间走，同时维护 left_max（l 左边出现过的最高柱子）和 right_max。每一步处理较矮的那一侧：如果 height[l] < height[r]，l 这一格的水位由 left_max 决定，因为右边至少有一根不矮于 height[l] 的柱子（就是 height[r]），所以右边最高一定不小于 height[l]，水位只可能被左边卡住。存水量是 left_max - height[l]，然后 l 右移。否则对称地处理右侧。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(height): l, r = 0, len(height) - 1 left_max = right_max = 0 water = 0 while l < r: if height[l] < height[r]: # 左边更矮：左边这一格的水位只由 left_max 决定（右边一定有不矮于它的柱子） left_max = max(left_max, height[l]) water += left_max - height[l] l += 1 else: # 右边不高于左边：对称 right_max = max(right_max, height[r]) water += right_max - height[r] r -= 1 return water

Java · 解法代码class Solution { public int trap(int[] height) { int l = 0, r = height.length - 1; int leftMax = 0, rightMax = 0, water = 0; while (l < r) { if (height[l] < height[r]) { // 左边更矮：这一格的水位只由 leftMax 决定 leftMax = Math.max(leftMax, height[l]); water += leftMax - height[l]; l++; } else { // 右边不高于左边：对称 rightMax = Math.max(rightMax, height[r]); water += rightMax - height[r]; r--; } } return water; } }

四种做法：答案一致，耗时对比

我在 Python 里实现了另外两种做法：单调栈（栈里放下标，遇到更高的柱子就弹出并计算这一层的水）和前后缀最大值数组（先算出每一格左边和右边的最高值，再求和）。在 20000 个随机柱高数组上验证了四种做法的答案，并在长度 1 万、10 万、100 万的随机柱高上比较了耗时（每个取三次中最快的一次）：

n=   10000: 双指针     0.73 ms    单调栈     1.85 ms    前后缀最大值     1.79 ms
n=  100000: 双指针     7.35 ms    单调栈    18.41 ms    前后缀最大值    17.80 ms
n= 1000000: 双指针    73.49 ms    单调栈   185.90 ms    前后缀最大值   179.06 ms

四种做法答案完全一致。三种线性做法里，双指针最快（100 万时 73.5ms），单调栈（185.9ms）和前后缀数组（179.1ms）相近，约慢 2.4 到 2.5 倍。双指针只需要 O(1) 额外空间，前后缀数组需要 O(n)，单调栈最坏 O(n)。这里只测了 Python 的耗时，其他语言里的排序可能不同。

Java Security Parameters:算法限制如何影响兼容性

jdk.tls.disabledAlgorithms 与 jdk.certpath.disabledAlgorithms 决定了 Java 拒绝哪些协议、套件和证书算法。三个 JDK 版本的默认值有什么不同?放宽或收紧会发生什么?这篇逐项真实运行,包括 JDK 17、21、27 的对比。

协议与套件的禁用

实测 · 本机执行输出 
  TLSv1.3  → 握手成功:TLSv1.3 TLS_AES_256_GCM_SHA384
  TLSv1.2  → 握手成功:TLSv1.2 TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384
  TLSv1.1  → 握手失败:SSLHandshakeException: No appropriate protocol (protocol is disabled or cipher suites are inappropriate)
  TLSv1    → 握手失败:SSLHandshakeException: No appropriate protocol (protocol is disabled or cipher suites are inappropriate)
  TLSv1.2 + 套件 TLS_RSA_WITH_AES_128_CBC_SHA(RSA 密钥交换,无前向保密)→ 握手失败:SSLHandshakeException: No appropriate protocol (protocol is disabled or cipher suites are inappropriate)
  TLSv1.2 + 套件 TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA → 握手成功:TLSv1.2 TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA
  TLSv1.2 + 套件 TLS_RSA_WITH_3DES_EDE_CBC_SHA → 握手失败:SSLHandshakeException: No appropriate protocol (protocol is disabled or cipher suites are inappropriate)

证书路径的算法限制

实测 · 本机执行输出 
  正常链 [leaf_sha256, ica] 信任 root → 通过
  叶子用 SHA1withRSA 签名 [leaf_sha1, ica] → 通过
  中间证书用 SHA1withRSA 签名 [leaf_viasha1, ica_sha1] → 通过
  512 位 RSA 的叶子 [leaf_rsa512, ica] → 失败:Algorithm constraints check failed on keysize limits: RSA 512 bit key used with certificate: CN=localhost(原因 ALGORITHM_CONSTRAINED)
  1024 位 RSA 的叶子 [leaf_rsa1024, ica] → 通过
  根证书(信任锚)自己的签名算法是 SHA1withRSA 时(root_sha1 作为锚,链 [leaf_underroot_sha1root])→ 通过(信任锚自身的签名算法不被检查)
  --- 用 -Djava.security.properties 收紧:jdk.certpath.disabledAlgorithms=MD2, MD5, SHA1, RSA keySize < 2048 ---
  正常链 [leaf_sha256, ica] 信任 root → 通过
  叶子用 SHA1withRSA 签名 [leaf_sha1, ica] → 失败:Algorithm constraints check failed on disabled algorithm: SHA1 used with certificate: CN=localhost(原因 ALGORITHM_CONSTRAINED)
  中间证书用 SHA1withRSA 签名 [leaf_viasha1, ica_sha1] → 失败:Algorithm constraints check failed on disabled algorithm: SHA1 used with certificate: CN=Sec ICA SHA1(原因 ALGORITHM_CONSTRAINED)
  512 位 RSA 的叶子 [leaf_rsa512, ica] → 失败:Algorithm constraints check failed on keysize limits: RSA 512 bit key used with certificate: CN=localhost(原因 ALGORITHM_CONSTRAINED)

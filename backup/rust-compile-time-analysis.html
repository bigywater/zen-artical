    本文用到的工具与边界

    • 本机 macOS 27 arm64 / rustc 1.98.1(brew)/ cargo 1.98.1;单个文件用 rustc 直接编译,需要依赖时用 cargo(经代理从 crates.io 下载);计时用 std::time::Instant,数字每次运行会有小幅抖动。cargo 1.98.1 稳定版;time-passes 与 print-mono-items 用 RUSTC_BOOTSTRAP=1;本机 10 核
    • 没有验证:更大的真实项目(几百个依赖)上的结果、cargo build --timings=json 的机器可读输出、-Z threads 并行前端、使用 lld/mold 等其它链接器的效果、sccache 等缓存工具、-Z self-profile 的细粒度分析
    • 同一个项目的干净构建:第一节带 --timings 的那次是 5.05 秒,第二节不带 --timings 的默认并行 3 次中位数是 3.2 秒。没有验证这个差别是 --timings 本身的开销、第一次运行的缓存状态还是别的原因,所以文中把第一节的各单元时间当作「这一次运行里的相对关系」

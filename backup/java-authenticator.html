Authenticator:集中处理网络认证挑战

遇到 401 或 407 时 Java 会怎么处理?谁来提供口令、会重试几次、凭证被缓存多久、全局设置会影响谁?这篇用本机的真实 HTTP 服务逐项验证。

20 vs 4
错误口令时 Authenticator 被调用的次数:HttpURLConnection(之后返回 401)与 HttpClient(之后抛 IOException,限制 3 次重试)
MD5 被拒绝
JDK 21 默认拒绝 algorithm=MD5 的 Digest 认证(Authenticator 仍被调用,但不发送凭证)
HttpClient 不用
Authenticator.setDefault 对 java.net.http.HttpClient 无效,需要 HttpClient.Builder.authenticator

反射与 final

实测 · 本机执行输出 
  编译期常量 final int inst = 1:setAccessible(true) 之后 f.setInt(b, 99) 成功,反射读 = 99,直接 b.inst = 1(javac 把常量 1 内联进了读取处,反射改的值读不到)
  构造器里赋值的 final int computed = 5:f.setInt(b, 99) 成功,反射读 = 99,直接 b.computed = 99,b.readComputed() = 99
  热循环(200 万次,已 JIT)里读 computed 求和 = 198000000(每次都读到 99 应是 198000000;读到旧值 5 则是 10000000)
  static final 字段 STATIC:f.setInt 抛 IllegalAccessException: Can not set static final int field Main$Box.STATIC to (int)5
  record 的字段 v:f.setInt 抛 IllegalAccessException: Can not set final int field Main$Rec.v to (int)5

本步的对象

    本文用到的工具与边界

    • 本机 macOS 27 arm64 / rustc 1.98.1(brew)/ cargo 1.98.1;单个文件用 rustc 直接编译,需要依赖时用 cargo(经代理从 crates.io 下载);计时用 std::time::Instant,数字每次运行会有小幅抖动。nightly 工具链用 rustup 装在隔离目录(不影响 brew 的 rustc):rustc 1.101.0-nightly (21b707e3f 2026-09-30)、miri 0.1.0 (21b707e3f9 2026-09-30)。cargo-bloat 0.12.1、cargo-llvm-lines 0.4.48(cargo install --locked,装在隔离目录);size/nm/strip 为 macOS 自带工具;选项通过 CARGO_PROFILE_RELEASE_* 环境变量设置
    • 没有验证:Linux 的 ELF 二进制(符号表与段的划分不同)、-Z build-std 重编标准库(进一步缩小 std 的部分)、upx 等压缩、cargo bloat 对 --time 的编译时间归因、符号名里的泛型实例化份数更多的程序
    • cargo-bloat 的数字是工具的估算(它自己的提示是「guesswork」),不是精确值

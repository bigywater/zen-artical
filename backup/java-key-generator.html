KeyGenerator:生成对称密钥的参数边界

生成一个对称密钥看起来是两行代码,但默认长度会随 JDK 版本变化,各算法接受的长度各不相同,随机源也完全由调用者决定。这篇逐项实测。

128 → 256 位
AES 不调用 init 时的默认密钥长度:JDK 17 与 JDK 21 / 27
同一个密钥
种子固定的 SHA1PRNG 作为随机源时,两个全新的 KeyGenerator 生成的 AES 密钥
0 个重复
8 线程共用一个 KeyGenerator 生成的 20 万个密钥中的重复数

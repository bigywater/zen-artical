Trait Object 与动态分发

泛型在编译期选择实现,trait object 在运行时选择。这篇把 dyn Trait 拆开看:它为什么只能放在指针后面、胖指针里装了什么、vtable 里记着什么,以及它和泛型在代码生成上的差别。

16 字节
&dyn Trait / Box 的大小(数据指针 + vtable 指针)
8 / 40 / 0
从 vtable 里读出的 Circle / Big / Unit 的 size,与 size_of 一致
1 vs 2
&dyn 函数与泛型函数(两个类型)生成的函数个数

vtable 里有什么

实测 · 本机执行输出 
  源码:
      1 | use std::mem::{size_of, align_of, transmute};
      2 | trait Shape { fn area(&self) -> f64; }
      3 | struct Circle(f64);                  // 8 字节
      4 | struct Big { a: [u64; 5] }           // 40 字节
      5 | struct Unit;                          // 0 字节
      6 | impl Shape for Circle { fn area(&self) -> f64 { self.0 } }
      7 | impl Shape for Big { fn area(&self) -> f64 { self.a[0] as f64 } }
      8 | impl Shape for Unit { fn area(&self) -> f64 { 0.0 } }
      9 | fn parts(s: &dyn Shape) -> (usize, usize) { unsafe { transmute::<&dyn Shape, (usize, usize)>(s) } }
     10 | fn vt_size_align(vt: usize) -> (usize, usize) { let p = vt as *const usize; unsafe { (*p.add(1), *p.add(2)) } }   // 观察到的布局:[drop_in_place, size, align, 方法...]
     11 | fn main() {
     12 |     let (c1, c2, b, u) = (Circle(1.0), Circle(2.0), Big { a: [1; 5] }, Unit);
     13 |     let (d1, v1) = parts(&c1); let (d2, v2) = parts(&c2); let (_d3, v3) = parts(&b); let (_d4, v4) = parts(&u);
     14 |     println!("Circle 的两个对象:数据地址不同 {},vtable 地址相同 {}", d1 != d2, v1 == v2);
     15 |     println!("Circle 与 Big 的 vtable 不同:{};Circle 与 Unit 的 vtable 不同:{}", v1 != v3, v1 != v4);
     16 |     for (name, vt, sz, al) in [("Circle", v1, size_of::<Circle>(), align_of::<Circle>()), ("Big", v3, size_of::<Big>(), align_of::<Big>()), ("Unit", v4, size_of::<Unit>(), align_of::<Unit>())] {
     17 |         let (s, a) = vt_size_align(vt);
     18 |         println!("{:<7} vtable 里读出 size = {:>2}, align = {};size_of / align_of = {} / {}", name, s, a, sz, al);
     19 |     }
     20 | }
  编译:成功
  运行(退出码 0):
    Circle 的两个对象:数据地址不同 true,vtable 地址相同 true
    Circle 与 Big 的 vtable 不同:true;Circle 与 Unit 的 vtable 不同:true
    Circle  vtable 里读出 size =  8, align = 8;size_of / align_of = 8 / 8
    Big     vtable 里读出 size = 40, align = 8;size_of / align_of = 40 / 8
    Unit    vtable 里读出 size =  0, align = 1;size_of / align_of = 0 / 1

vtable 的布局不是语言保证的稳定接口,这里只是在当前编译器版本上观察。胖指针的更多内容见Trait Object 的胖指针。

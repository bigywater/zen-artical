实测 · 本机执行输出 
  Response('hi')                                           → 200 OK | text/html; charset=utf-8 | b'hi' | {'Content-Type': 'text/html; charset=utf-8', 'Content-Length': '2'}
  Response('hi', 201)                                      → 201 CREATED | text/html; charset=utf-8 | b'hi' | {'Content-Type': 'text/html; charset=utf-8', 'Content-Length': '2'}
  Response('hi', '202 自定义')                                → 202 自定义 | text/html; charset=utf-8 | b'hi' | {'Content-Type': 'text/html; charset=utf-8', 'Content-Length': '2'}
  Response('hi', mimetype='text/plain')                    → 200 OK | text/plain; charset=utf-8 | b'hi' | {'Content-Type': 'text/plain; charset=utf-8', 'Content-Length': '2'}
  Response('hi', content_type='text/csv')                  → 200 OK | text/csv | b'hi' | {'Content-Type': 'text/csv', 'Content-Length': '2'}
  Response('hi', content_type='text/plain; charset=latin-1') → 200 OK | text/plain; charset=latin-1 | b'hi' | {'Content-Type': 'text/plain; charset=latin-1', 'Content-Length': '2'}
  Response('hi', headers={'X-A': '1'})                     → 200 OK | text/html; charset=utf-8 | b'hi' | {'X-A': '1', 'Content-Type': 'text/html; charset=utf-8', 'Content-Length': '2'}
  Response(b'\x00\x01')                                    → 200 OK | text/html; charset=utf-8 | b'\x00\x01' | {'Content-Type': 'text/html; charset=utf-8', 'Content-Length': '2'}
  Response(['a', 'b'])                                     → 200 OK | text/html; charset=utf-8 | b'ab' | {'Content-Type': 'text/html; charset=utf-8'}
  Response()                                               → 200 OK | text/html; charset=utf-8 | b'' | {'Content-Type': 'text/html; charset=utf-8'}

status 与 status_code

实测 · 本机执行输出 
  设 status_code=404 后 status = 404 NOT FOUND
  设 status="418 我是茶壶" 后 status_code = 418 | status = 418 我是茶壶
  Response(status=99) → 99 UNKNOWN / 99
  Response(status=1000) → 1000 UNKNOWN / 1000
  Response(status='999 x') → 999 x / 999
  Response(status='abc') → 0 abc / 0

headers

实测 · 本机执行输出 
  类型: Headers
  结果: [('Content-Type', 'text/html; charset=utf-8'), ('Content-Length', '1'), ('x-one', '1b'), ('X-Multi', 'a'), ('X-Multi', 'b'), ('X-Ext', 'e')]
  getlist("X-Multi") = ['a', 'b'] | r.headers["x-one"] = 1b | "X-Ext" in headers: True
  删除 X-Ext 后: ['Content-Type', 'Content-Length', 'x-one', 'X-Multi', 'X-Multi']

头注入

实测 · 本机执行输出 
  值里有 \n → ValueError: Header values must not contain newline characters.
  值里有 \r\n → ValueError: Header values must not contain newline characters.
  值里有 \x00 → 设置成功: 'a\x00b'

data 与 Content-Length

实测 · 本机执行输出 
  初始 Content-Length = 5 | data = b'hello'
  set_data 之后 Content-Length = 13 (UTF-8 字节数) | 字符数 = 5
  迭代器形式的 response:Content-Length = None | is_sequence = True | is_streamed = False
  生成器形式:Content-Length = None | is_sequence = False | is_streamed = True

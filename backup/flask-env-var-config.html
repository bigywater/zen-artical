字符串的陷阱

实测 · 本机执行输出 
  bool(os.environ["T_FALSE"]) = True | bool("0") = True | bool("") = False | os.environ["T_NUM"] + 1 → TypeError: can only concatenate str (not "int") to str
  自己写的 env_bool: {'T_FALSE': False, 'T_ZERO': False, 'T_EMPTY': False, 'T_NUM': False, 'T_MISSING': False}
  os.environ["不存在"] → KeyError 'NOPE_X'
  os.environ.get("不存在") = None | .get(key, 默认) = 默认

.env 与真实环境变量

实测 · 本机执行输出 
  没有 --app(来自 .flaskenv 的 FLASK_APP=app),没设任何环境变量: {'DEBUG': False, 'FLASK_DEBUG': None, 'GREETING': 'prefixed-from-dotenv', 'MODE': 'from-dotenv', 'SECRET': 's3cret'}
  同名真实环境变量(MODE、FLASK_GREETING)已设置: {'DEBUG': False, 'FLASK_DEBUG': None, 'GREETING': 'real-prefixed', 'MODE': 'from-real-env', 'SECRET': 's3cret'}
  (.flaskenv 里写的是 MODE=from-flaskenv,.env 里写的是 MODE=from-dotenv;第一次输出里 MODE = from-dotenv:同名时 .env 的值生效)

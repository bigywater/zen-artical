signals:引擎在哪些时刻发出信号

Scrapy 的信号有哪些、什么时候发、带什么参数?处理函数抛异常、写成 async 会怎样?能不能用信号提前中止一次下载?这篇给全部 22 个信号接上记录器,在一次包含各种情形的抓取里量出来。

请求生命周期的四个信号(scheduled、reached_downloader、left_downloader、response_downloaded)每个下载的请求各触发一次;response_received 比它们少,因为被重定向这类中间件消费的响应不会走到引擎。

顺序

实测 · 本机执行输出 
  首次出现的顺序:spider_opened → engine_started → request_scheduled → request_reached_downloader → headers_received → bytes_received → response_downloaded → request_left_downloader → response_received → robots_parsed → scheduler_empty → request_dropped → spider_error → item_scraped → item_dropped → item_error → spider_idle → spider_closed → feed_slot_closed → feed_exporter_closed → engine_stopped
  最后 6 个事件:scheduler_empty → spider_idle → spider_closed → feed_slot_closed → feed_exporter_closed → engine_stopped

每个请求的信号链是 scheduled → reached → headers_received → bytes_received → response_downloaded → left → response_received;结束时 spider_idle → spider_closed → feed_* → engine_stopped。

  StopDownload(fail=False):[{'sig': 'bytes_received', 'n': 65536}, {'who': 'callback', 'body': 65536, 'status': 200}];stats downloader/response_bytes=65670
  StopDownload(fail=True):[{'sig': 'bytes_received', 'n': 65536}, {'who': 'errback', 'exc': 'StopDownload', 'resp': 65536}];stats downloader/response_bytes=None
  不中止:[{'who': 'callback', 'body': 300000, 'status': 200}];bytes_received 触发了 5 次;response_bytes=300134

headers_received 和 bytes_received 的处理函数可以抛 StopDownload,fail 参数决定把截断的响应交给回调还是 errback。

弱引用

实测 · 本机执行输出 
  不保存引用的局部函数:处理函数被调用 0 次
  把函数挂到 spider 属性上:处理函数被调用 1 次

connect 默认只存弱引用,局部函数要自己保存引用。

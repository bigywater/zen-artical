G1 Humongous Object:大对象为什么会改变回收节奏

G1 里多大的对象算「巨型」?它为什么浪费空间?没有引用之后要等并发周期才能回收吗?这篇用日志里的 Humongous Allocation 作为信号,逐个字节数地逼近阈值。

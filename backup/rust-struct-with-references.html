Struct 中保存引用

把引用存进结构体是 Rust 里「零拷贝」的主要手段,也是生命周期标注最常出现的地方。这篇验证它的语法要求、它对数据寿命和修改的限制,并用一个自定义的计数分配器量出它省下了多少堆分配。

E0106
结构体字段是引用却没声明生命周期
13 vs 10013
借用版与拥有版分词器的堆分配次数(1 万个词)
<'a, 'b>
一个结构体可以有多个独立的生命周期参数

零拷贝的收益

实测 · 本机执行输出 
  源码:
      1 | use std::alloc::{GlobalAlloc, Layout, System};
      2 | use std::sync::atomic::{AtomicUsize, Ordering};
      3 | struct Counting;
      4 | static ALLOCS: AtomicUsize = AtomicUsize::new(0);
      5 | unsafe impl GlobalAlloc for Counting {
      6 |     unsafe fn alloc(&self, l: Layout) -> *mut u8 { ALLOCS.fetch_add(1, Ordering::Relaxed); unsafe { System.alloc(l) } }
      7 |     unsafe fn dealloc(&self, p: *mut u8, l: Layout) { unsafe { System.dealloc(p, l) } }
      8 | }
      9 | #[global_allocator] static A: Counting = Counting;
     10 | 
     11 | struct Tokens<'a> { words: Vec<&'a str> }                 // 借用:切片指回原文
     12 | struct OwnedTokens { words: Vec<String> }                 // 拥有:每个词一个 String
     13 | fn main() {
     14 |     let text: String = (0..10_000).map(|i| format!("word{i} ")).collect();
     15 |     let before = ALLOCS.load(Ordering::Relaxed);
     16 |     let t = Tokens { words: text.split_whitespace().collect() };
     17 |     let a1 = ALLOCS.load(Ordering::Relaxed) - before;
     18 |     let before = ALLOCS.load(Ordering::Relaxed);
     19 |     let o = OwnedTokens { words: text.split_whitespace().map(String::from).collect() };
     20 |     let a2 = ALLOCS.load(Ordering::Relaxed) - before;
     21 |     println!("文本里有 {} 个词", t.words.len());
     22 |     println!("借用版(Vec<&str>)  堆分配 {} 次", a1);
     23 |     println!("拥有版(Vec<String>)堆分配 {} 次", a2);
     24 |     println!("第 5000 个词:{} / {};两者内容相同:{}", t.words[5000], o.words[5000], t.words[5000] == o.words[5000]);
     25 | }
  编译:成功
  运行(退出码 0):
    文本里有 10000 个词
    借用版(Vec<&str>)  堆分配 13 次
    拥有版(Vec<String>)堆分配 10013 次
    第 5000 个词:word5000 / word5000;两者内容相同:true

分配次数通过自定义 #[global_allocator] 计数得到(只数 alloc 次数,不含字节数);release 构建。自定义分配器相关的更多内容这里没有展开。

LeetCode 100. 相同的树

给定两棵二叉树，判断它们是否相同：结构相同，并且对应位置的结点值也相同。递归的想法很自然：两棵树都是空，相同；一棵空另一棵不空，不同；两个根的值不同，不同；否则左子树和右子树都必须相同。这道题是二叉树递归里最简单的一题，有一个常见的想法值得实测：能不能只比较两棵树的中序遍历序列？本文用穷举展示答案是不能，给出五种语言的实现，并把两棵树同时往下走的过程做成分步演示。

陷阱：只比较中序遍历序列，看不出形状的差别

把两棵树都做中序遍历，得到两个数字序列，如果序列相同就认为树相同——这是错误的：不同形状的树可以有相同的中序序列。比如 [2, 1, 3]（2 是根，1、3 是左右孩子）和 [1, null, 2, null, 3]（1 → 2 → 3 的右链）的中序序列都是 1, 2, 3，但它们完全不同。下面是这种写法的真实结果，以及一个更强的穷举：用 1 到 n 组成的所有二叉搜索树，它们的中序序列全都是 1, 2, ..., n：

[2, 1, 3] 与 [1, None, 2, None, 3]: 只比较中序 -> True    solve -> False

穷举：用 1 到 n 组成的所有二叉搜索树（它们的中序序列全都是 1..n），任取两棵：
n=3: 5 棵树，共 25 对（有序对），其中不同的有 20 对；只比较中序时全部 20 对不同的树都被误判为相同，solve 判对 20 对
n=4: 14 棵树，共 196 对（有序对），其中不同的有 182 对；只比较中序时全部 182 对不同的树都被误判为相同，solve 判对 182 对
n=5: 42 棵树，共 1764 对（有序对），其中不同的有 1722 对；只比较中序时全部 1722 对不同的树都被误判为相同，solve 判对 1722 对
n=6: 132 棵树，共 17424 对（有序对），其中不同的有 17292 对；只比较中序时全部 17292 对不同的树都被误判为相同，solve 判对 17292 对

n = 4 时有 14 棵不同的二叉搜索树（卡特兰数），它们共有 196 个有序对，其中 182 对是不同的树，只比较中序序列时这 182 对全部被误判成相同；n = 5、6 时同样是全部（1722 对、17292 对）被误判，而 solve 全部判对。要区分不同的树，中序序列必须再加上前序（或后序）序列，或者像本文这样直接递归比较结构。

同时递归：五种语言的实现

isSameTree(p, q)：两个都是空返回真；只有一个是空返回假；两个根的值不同返回假；否则返回 isSameTree(p.left, q.left) 且 isSameTree(p.right, q.right)。所有的比较都是在两棵树的对应位置上同步进行的。时间 O(min(p 的结点数, q 的结点数))，空间是递归深度。Python、Java、Go、JavaScript、C++ 都是真实编译运行的；测试程序把层序数组建成结点对象再调用。

Python · 解法代码class TreeNode: def __init__(self, val=0, left=None, right=None): self.val = val self.left = left self.right = right def is_same_tree(p, q): if p is None and q is None: # 两边都空：相同 return True if p is None or q is None: # 一边空一边不空：结构不同 return False if p.val != q.val: # 结点的值不同 return False return is_same_tree(p.left, q.left) and is_same_tree(p.right, q.right) # 左右子树都要相同

Java · 解法代码class TreeNode { int val; TreeNode left, right; TreeNode(int v) { val = v; } } class Solution { public boolean isSameTree(TreeNode p, TreeNode q) { if (p == null && q == null) return true; // 两边都空：相同 if (p == null || q == null) return false; // 一边空一边不空：结构不同 if (p.val != q.val) return false; // 结点的值不同 return isSameTree(p.left, q.left) && isSameTree(p.right, q.right); // 左右子树都要相同 } }

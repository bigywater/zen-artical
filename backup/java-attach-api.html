Attach API:如何连接一个正在运行的 JVM

jcmd、jstack、各种 APM 都是通过 Attach API 连进正在运行的 JVM 的。这篇自己写 attach 的客户端,把握手、读取属性、动态加载 agent 与失败情形逐项做一遍(Instrumentation 与 HotSwap 见前面的篇目)。

证书里写了什么

实测 · 本机执行输出 
  subject=subject=CN=kube-apiserver;issuer=issuer=CN=kubernetes
  有效期:notBefore=Oct 10 17:56:11 2026 GMT;notAfter=Oct 10 18:01:11 2027 GMT(共 365 天)
  SAN:DNS:kubernetes, DNS:kubernetes.default, DNS:kubernetes.default.svc, DNS:kubernetes.default.svc.cluster.local, DNS:kx-main-control-plane, DNS:localhost, IP Address:10.96.0.1, IP Address:172.18.0.3, IP Address:127.0.0.1
  用途:TLS Web Server Authentication;CA 证书 ca.crt 的有效期:notAfter=Oct  7 08:03:13 2036 GMT
  apiserver-kubelet-client:subject=subject=CN=kube-apiserver-kubelet-client;issuer=issuer=CN=kubernetes
  apiserver-etcd-client:subject=subject=CN=kube-apiserver-etcd-client;issuer=issuer=CN=etcd-ca
  etcd server:subject=subject=CN=kx-main-control-plane;issuer=issuer=CN=etcd-ca
  admin.conf 内嵌的客户端证书:subject=O=kubeadm:cluster-admins, CN=kubernetes-admin;super-admin.conf:subject=O=system:masters, CN=kubernetes-super-admin
  controller-manager.conf:subject=CN=system:kube-controller-manager;scheduler.conf:subject=CN=system:kube-scheduler

apiserver.crt:subject CN=kube-apiserver,issuer CN=kubernetes,有效期 365 天,SAN 有 kubernetes、kubernetes.default、kubernetes.default.svc、kubernetes.default.svc.cluster.local、kx-main-control-plane、localhost、10.96.0.1、172.18.0.3、127.0.0.1,用途是 TLS Web Server Authentication。客户端证书的 subject 就是身份:admin.conf 是 O=kubeadm:cluster-admins, CN=kubernetes-admin(靠 RBAC 绑定 cluster-admin),super-admin.conf 是 O=system:masters, CN=kubernetes-super-admin(system:masters 组绕过 RBAC),controller-manager、scheduler 分别是 CN=system:kube-controller-manager、CN=system:kube-scheduler。

/var/lib/kubelet/pki/ 下 kubelet-client-current.pem 是符号链接,指向带时间戳的 kubelet-client-2026-10-10-08-03-14.pem,subject 是 O=system:nodes, CN=system:node:kx-main-control-plane;配置里 rotateCertificates: true,到期前会自动轮转(靠 CSR,见 k21)。kubelet.crt(10250 端口的服务证书)是自签的,issuer 是 kx-main-control-plane-ca@…,不是集群 CA 签的;serverTLSBootstrap 没设置。

续期要重启吗

实测 · 本机执行输出 
  renew 前:文件里 serial=3EA9911F6D50D107 notBefore=Oct 10 17:56:11 2026 GMT;apiserver 实际出示 serial=3EA9911F6D50D107 notBefore=Oct 10 17:56:11 2026 GMT;apiserver 容器启动时间 2026-10-10T18:01:12
  kubeadm certs renew apiserver:certificate for serving the Kubernetes API renewed
  renew 后马上读文件:serial=5A98A8B813D8C969 notBefore=Oct 10 17:56:32 2026 GMT
  不重启 apiserver,0.1 秒后它出示的证书就变成了新的:serial=5A98A8B813D8C969 notBefore=Oct 10 17:56:32 2026 GMT;容器没有重启(同一个容器 True,启动时间仍是 2026-10-10T18:01:12)
  kubeadm certs check-expiration 里 apiserver 一行:apiserver                  Oct 10, 2027 18:01 UTC   364d            ca                      no(它读的是磁盘上的文件)
  kubectl 访问正常:ok

kubeadm certs renew apiserver 后,磁盘上的 apiserver.crt 立刻变成新的(serial 从 3EA9911F6D50D107 变为 5A98A8B813D8C969;notBefore 比当前时间早 5 分钟,这是 kubeadm 为容忍时钟偏差回拨的)。不重启 apiserver,0.1 秒就发现它对外出示的证书已经是新的——容器没有重启(同一个容器,启动时间不变),说明 apiserver 会自动重新加载服务证书文件。kubeadm certs check-expiration 里 apiserver 一行随之变成 Oct 10, 2027 18:01 UTC;它读的是磁盘文件,不是进程里的状态。

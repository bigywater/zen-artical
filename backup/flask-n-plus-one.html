网络延迟放大 N+1

实测 · 本机执行输出 
  单向延迟       /bad(1+N 条)      /good(2 条)     倍数
     0 ms           23.1 ms         3.0 ms     7.7x
     1 ms          408.6 ms        16.3 ms    25.1x
     5 ms         1481.8 ms        70.8 ms    20.9x

延迟代理是本篇自己用 asyncio 写的,只是模拟「数据库不在本机」,不代表某个真实网络的数字。

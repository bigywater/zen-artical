LeetCode 63. 不同路径 II

和上一题一样，机器人从网格左上角走到右下角，只能向右或向下；不同的是网格里有障碍（1 表示障碍，0 表示空地），路径不能经过障碍。动态规划的思路不变：走到 (i, j) 的路径数等于上面那格加左边那格，但障碍格子的路径数是 0。边界情形需要小心：起点本身是障碍、终点本身是障碍、第一行或第一列被障碍截断。本文用真实数据展示"第一行第一列一律初始化为 1"的写法会错多少，验证动态规划与枚举全部路径的答案一致，给出五种语言的实现，并把带障碍的填表做成分步演示。

陷阱：第一行和第一列不能一律填 1

没有障碍时，第一行、第一列每个格子都只有一条路，所以上一题可以把它们全部初始化为 1。有障碍时就不对了：第一行里某个格子是障碍，那么它右边所有的格子都走不到（只能从左边来）；第一列同理。下面是"第一行第一列一律初始化为 1"的写法与 solve 的真实结果：

[[0, 1, 0]]（一行，中间是障碍）应该是 0，那种写法得到 1；[[1, 0], [0, 0]]（起点是障碍）应该是 0，得到 2。最后一行的统计是：在随机生成的 20000 个网格里（每个格子 25% 是障碍），这种写法与正确答案不同的有 11536 个，占 57.7%。而官方示例（[[0, 0, 0], [0, 1, 0], [0, 0, 0]]）两种写法都是 2，因为障碍不在第一行第一列，所以只用官方示例测不出这个错误。

一维动态规划：五种语言的实现

dp[j] 是走到当前行第 j 列的路径数。初始化：dp[0] 在起点不是障碍时是 1，否则是 0，其余是 0。按行、按列遍历：遇到障碍，dp[j] = 0；否则如果不是第一列，dp[j] += dp[j - 1]（dp[j] 原来的值是从上面来，dp[j - 1] 是从左边来）。第一列不是障碍时 dp[0] 保持上一行的值，也就是从上面来的路径数。最后返回 dp[n - 1]。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(grid): m, n = len(grid), len(grid[0]) dp = [0] * n # dp[j]：走到当前行第 j 列的路径数 dp[0] = 1 if grid[0][0] == 0 else 0 # 起点本身是障碍就一条路都没有 for i in range(m): for j in range(n): if grid[i][j] == 1: dp[j] = 0 # 障碍格子：没有路能走到这里 elif j > 0: dp[j] += dp[j - 1] # 到 (i, j) = 从上面来（旧的 dp[j]）+ 从左边来（dp[j-1]） return dp[n - 1]

Java · 解法代码class Solution { public int uniquePathsWithObstacles(int[][] grid) { int m = grid.length, n = grid[0].length; int[] dp = new int[n]; // dp[j]：走到当前行第 j 列的路径数 dp[0] = grid[0][0] == 0 ? 1 : 0; // 起点本身是障碍就一条路都没有 for (int i = 0; i < m; i++) { for (int j = 0; j < n; j++) { if (grid[i][j] == 1) dp[j] = 0; // 障碍格子：没有路能走到这里 else if (j > 0) dp[j] += dp[j - 1]; // 到 (i, j) = 从上面来（旧的 dp[j]）+ 从左边来（dp[j-1]） } } return dp[n - 1]; } }

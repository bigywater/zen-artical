请求日志与 MDC:每个请求带 trace id

怎么让每个请求的日志都带同一个 trace id?为什么 @Async 和 CompletableFuture 里的日志没有 id?Callable 的日志呢?忘了清 MDC 会怎样?CommonsRequestLoggingFilter 打出来的日志安全吗?这篇在 Spring Boot 4.0.8 上逐个把线程名和 MDC 打印出来。

0 / 4
装了 TaskDecorator 之后,supplyAsync、new Thread、ASYNC 派发里带 id 的日志条数——仍然没有
2 / 2
没带 X-Request-Id 的请求里,日志却带着上一个请求 id 的个数(Filter 没清 MDC)
明文
includeHeaders=true 时 Authorization 和 Cookie 在日志里的样子

MDC 是线程局部的,@Async、Callable、CompletableFuture、new Thread 里都是空。

LeetCode 24. 两两交换链表中的节点

给定一个链表，把相邻的两个结点两两交换，返回新的头结点。要求真的交换结点，不能只交换结点里的值。链表长度是奇数时，最后一个结点保持原位。这道题没有算法上的技巧，全部难点在指针操作：每交换一对要改三个指针，顺序错了链表就断了。本文用真实的错误版本展示漏掉一步指针会得到什么，给出五种语言的实现，并把每一步改指针做成分步演示。

陷阱：漏掉一步指针，链表会丢结点

交换 prev 后面的一对 a、b 需要三步：让 a 接上 b 后面的部分，让 b 指向 a，让 prev 指向 b。第三步最容易漏，因为前两步已经把 a、b 的方向换过来了，看起来"已经交换完了"。下面是漏掉第三步的真实运行结果：

真实实测 · 本机执行输出

[1, 2]: 漏一步 -> [1]    solve -> [2, 1]
[1, 2, 3, 4]: 漏一步 -> [1, 3]    solve -> [2, 1, 4, 3]
[1, 2, 3, 4, 5, 6]: 漏一步 -> [1, 3, 5]    solve -> [2, 1, 4, 3, 6, 5]

漏掉第三步之后，prev 仍然指向 a，b 被甩在了链表外面：[1, 2, 3, 4] 只剩 [1, 3]，每一对里的第二个结点都丢了。结果不是乱序，而是缺结点，检查时容易被误认为是别的问题。

哑结点加三步改指针：五种语言的实现

先建一个哑结点，prev 指向它。只要 prev 后面还有两个结点，就取这一对 a、b，按上面三步改指针，然后让 prev 指向 a（它现在是这一对的第二个），继续下一对。哑结点让"头结点也被交换"这个情况不需要特判。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码class ListNode: def __init__(self, val=0, next=None): self.val = val self.next = next def swap_pairs(head): dummy = ListNode(0, head) prev = dummy # prev 始终指向"待交换的这一对"的前一个结点 while prev.next and prev.next.next: a, b = prev.next, prev.next.next a.next = b.next # 1) a 接到 b 后面的部分 b.next = a # 2) b 指向 a prev.next = b # 3) 前一个结点指向 b prev = a # a 现在是这一对的第二个，下一对从它后面开始 return dummy.next

Java · 解法代码class ListNode { int val; ListNode next; ListNode(int v) { val = v; } } class Solution { public ListNode swapPairs(ListNode head) { ListNode dummy = new ListNode(0); dummy.next = head; ListNode prev = dummy; // prev 始终指向"待交换的这一对"的前一个结点 while (prev.next != null && prev.next.next != null) { ListNode a = prev.next, b = prev.next.next; a.next = b.next; // 1) a 接到 b 后面的部分 b.next = a; // 2) b 指向 a prev.next = b; // 3) 前一个结点指向 b prev = a; // a 现在是这一对的第二个 } return dummy.next; } }

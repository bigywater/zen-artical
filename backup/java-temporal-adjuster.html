TemporalAdjuster:把日期规则变成可复用调整器

「下一个工作日」「每月最后一个星期五」这类规则,TemporalAdjuster 可以把它们变成一个可复用、可测试的值。这篇逐个验证内置调整器的边界,写一个自己的调整器并逐天比对,并看它能用在哪些时间类型上。

4018 / 0
自写 NEXT_WORKING_DAY 与手写循环比对的天数 / 不一致天数
03-06
2026-02 只有 4 个星期五,dayOfWeekInMonth(5, FRIDAY) 溢出到的日期
3 种失败
YearMonth、LocalTime、Instant 上用 NEXT_WORKING_DAY 抛 DateTimeException

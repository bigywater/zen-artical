JDBC Driver SPI:驱动如何被发现和加载

为什么现在不用再写 Class.forName("com.mysql.jdbc.Driver")?DriverManager 怎么在一堆驱动里选一个?驱动从别的类加载器加载会怎样?这篇用四个真实的嵌入式数据库驱动和一个自己写的驱动逐项验证。

4 个
没有 Class.forName 时 DriverManager 自动发现的驱动数(20 ms)
08001
No suitable driver 的 SQLState
3 种
让自己写的驱动被注册的方式:Class.forName、-Djdbc.drivers、服务文件

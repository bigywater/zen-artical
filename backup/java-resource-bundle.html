ResourceBundle:国际化资源的查找与回退

国际化消息文件的查找规则有一些反直觉的地方:默认 Locale 会混进回退链,编码有静默回退,缓存永不过期。这篇用临时目录里的真实文件逐项验证。

fr 而不是 base
默认 Locale = fr 时,请求没有对应文件的 en 或 ja 得到的 bundle
0xE9 在末尾
properties 文件最后一个字节是非法 UTF-8 时 getBundle 抛 MissingResourceException(其它位置的非法字节则静默回退 Latin-1)
-2
默认 Control.getTimeToLive,即 bundle 缓存永不过期

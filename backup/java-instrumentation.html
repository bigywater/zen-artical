Java Instrumentation:在类加载时插入观测逻辑

在类加载时插入观测逻辑,是 APM 与各种监控 agent 的基本做法。这篇自己写一个 Java agent(premain + ClassFileTransformer + ASM),验证它能看到哪些类、怎么插桩、失败时是什么样(Attach 与运行中修改在后面的篇目)。

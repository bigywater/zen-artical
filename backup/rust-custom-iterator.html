自定义 Iterator

自己写迭代器很简单,但要写得好需要几个小知识:结构体里放什么、怎样借用外部数据、要不要实现双端与精确长度、size_hint 的作用。这篇用四个例子逐条验证。

size_hint 的价值

实测 · 本机执行输出 
  源码:
      1 | struct NoHint(u32); struct WithHint(u32);
      2 | impl Iterator for NoHint { type Item = u32; fn next(&mut self) -> Option<u32> { if self.0 == 0 { None } else { self.0 -= 1; Some(self.0) } } }
      3 | impl Iterator for WithHint { type Item = u32; fn next(&mut self) -> Option<u32> { if self.0 == 0 { None } else { self.0 -= 1; Some(self.0) } } fn size_hint(&self) -> (usize, Option<usize>) { (self.0 as usize, Some(self.0 as usize)) } }
      4 | fn main() {
      5 |     let a: Vec<u32> = NoHint(1000).collect(); let b: Vec<u32> = WithHint(1000).collect();

LeetCode 22. 括号生成

给定 n 对括号，生成所有合法的括号组合。合法的意思是：每个右括号都能和前面某个未配对的左括号匹配。暴力做法是枚举全部 2^(2n) 个由 ( 和 ) 组成的串，再逐个检查；更好的做法是回溯，在生成的过程中只走合法的分支：左括号还没用满 n 个就可以放，右括号只有在"已放的左括号比右括号多"时才可以放。本文用真实运行的数据展示合法串的个数（卡特兰数）、剪枝带来的实际加速，给出五种语言的实现，并把回溯过程做成分步演示。

剪枝到底省了多少

"不剪枝"的版本同样用回溯，但每个位置都可以放两种括号，放满 2n 个之后再检查是否合法。它与本文的解法结果完全一致，只是慢得多。下面是真实耗时，每个规模取三次中最快的一次：

回溯：五种语言的实现

dfs(open, close) 记录已经放了几个左括号和几个右括号。路径长度达到 2n 时收集结果；否则如果左括号没用满就放左括号并递归，再撤销；如果右括号比左括号少就放右括号并递归，再撤销。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(n): res = [] path = [] def dfs(open_, close): if len(path) == 2 * n: res.append("".join(path)) return if open_ < n: # 左括号还没用完，可以放 path.append("(") dfs(open_ + 1, close) path.pop() if close < open_: # 右括号只能在"有未配对的左括号"时放 path.append(")") dfs(open_, close + 1) path.pop() dfs(0, 0) return res

Java · 解法代码class Solution { public List<String> generateParenthesis(int n) { List<String> res = new ArrayList<>(); dfs(n, 0, 0, new StringBuilder(), res); return res; } private void dfs(int n, int open, int close, StringBuilder path, List<String> res) { if (path.length() == 2 * n) { res.add(path.toString()); return; } if (open < n) { // 左括号还没用完，可以放 path.append('('); dfs(n, open + 1, close, path, res); path.deleteCharAt(path.length() - 1); } if (close < open) { // 右括号只能在"有未配对的左括号"时放 path.append(')'); dfs(n, open, close + 1, path, res); path.deleteCharAt(path.length() - 1); } } }

LeetCode 28. 找出字符串中第一个匹配项的下标

在字符串 haystack 里找到字符串 needle 第一次出现的起点下标，找不到返回 -1。最直接的做法是对每个起点逐字符比较，最坏是 O(n·m)；KMP 算法在失配时不回退 haystack 的指针，只依据 needle 自身的前缀结构把匹配长度退回去，总时间 O(n + m)。本文给出 KMP 的五种语言实现，用真实的字符比较次数和耗时展示两者在最坏输入上的差距，并把 KMP 的匹配和回退做成分步演示。

题意与示例

最坏情形：比较次数差了两个数量级

逐个起点比较的最坏情形是：haystack 全是 a，needle 是一长串 a 再加一个 b。每个起点都会比较到 needle 的最后一个字符才失配，然后整个比较作废、起点前移一格。下面是两种做法真实统计的字符比较次数：

真实实测 · 本机执行输出
字符比较次数：haystack = a*n，needle = a*(n/2-1)+b（最坏情形）
n=  500: 逐个起点比较     62750 次    KMP   1248 次
n= 1000: 逐个起点比较    250500 次    KMP   2498 次
n= 2000: 逐个起点比较   1001000 次    KMP   4998 次
n= 4000: 逐个起点比较   4002000 次    KMP   9998 次

n 每翻一倍，逐个起点比较的次数增加约 4 倍（62750、250500、1001000、4002000），是平方增长；KMP 的比较次数是 1248、2498、4998、9998，每翻一倍只翻一倍，是线性增长。n = 4000 时，逐个起点比较用了 400 万次，KMP 只用了不到 1 万次。

KMP：五种语言的实现

先算前缀表 lps：lps[i] 是 needle[0..i] 最长的"既是前缀又是后缀"的真前缀的长度。匹配时 k 表示已经匹配了 needle 的前 k 个字符：当前字符相同就 k 加一；失配就把 k 退到 lps[k-1]，重新比较当前字符，haystack 的下标一直不回退。k 等于 needle 的长度时匹配成功。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(haystack, needle): m = len(needle) lps = [0] * m # lps[i]：needle[0..i] 最长的"既是前缀又是后缀"的真前缀长度 k = 0 for i in range(1, m): while k and needle[i] != needle[k]: k = lps[k - 1] if needle[i] == needle[k]: k += 1 lps[i] = k k = 0 # k：当前已经匹配了 needle 的前 k 个字符 for i, ch in enumerate(haystack): while k and ch != needle[k]: # 失配：不回退 haystack，只把 k 退到 lps[k-1] k = lps[k - 1] if ch == needle[k]: k += 1 if k == m: return i - m + 1 return -1

Java · 解法代码class Solution { public int strStr(String haystack, String needle) { int m = needle.length(); int[] lps = new int[m]; // lps[i]：needle[0..i] 最长的"既是前缀又是后缀"的真前缀长度 for (int i = 1, k = 0; i < m; i++) { while (k > 0 && needle.charAt(i) != needle.charAt(k)) k = lps[k - 1]; if (needle.charAt(i) == needle.charAt(k)) k++; lps[i] = k; } int k = 0; // k：当前已经匹配了 needle 的前 k 个字符 for (int i = 0; i < haystack.length(); i++) { while (k > 0 && haystack.charAt(i) != needle.charAt(k)) k = lps[k - 1]; // 失配：只退 k，不回退 i if (haystack.charAt(i) == needle.charAt(k)) k++; if (k == m) return i - m + 1; } return -1; } }

Go · 解法代码func strStr(haystack, needle string) int { m := len(needle) lps := make([]int, m) // lps[i]：needle[0..i] 最长的"既是前缀又是后缀"的真前缀长度 for i, k := 1, 0; i < m; i++ { for k > 0 && needle[i] != needle[k] { k = lps[k-1] } if needle[i] == needle[k] { k++ } lps[i] = k } k := 0 // k：当前已经匹配了 needle 的前 k 个字符 for i := 0; i < len(haystack); i++ { for k > 0 && haystack[i] != needle[k] { // 失配：只退 k，不回退 i k = lps[k-1] } if haystack[i] == needle[k] { k++ } if k == m { return i - m + 1 } } return -1 }

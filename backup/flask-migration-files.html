手写数据迁移

实测 · 本机执行输出 
  空脚本里原来是 pass;手写的两个函数:
    def upgrade():
        op.execute("update user set email = name || '@example.com' where email = 'none'")
    def downgrade():
        op.execute("update user set email = 'none' where email like '%@example.com'")
  执行前: [('bob', 'none')]
  upgrade 后: [('bob', 'bob@example.com')] | 退出码 0
  downgrade 后: [('bob', 'none')] | 退出码 0

实测 · 本机执行输出

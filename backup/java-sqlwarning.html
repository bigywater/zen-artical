SQLWarning:数据库的非致命信号

数据库说「我做了点处理但没有报错」的信号就是 SQLWarning。这篇看警告挂在哪、能保留多久、什么情况下会被吞掉,以及它们如何让数据被悄悄改写。

v=abc n=127
MySQL 非严格模式下插入 'abcdef' 与 300 到 varchar(3) / tinyint 的实际结果,只有警告没有异常
[1, 1, 1] 且无警告
MySQL 非严格模式下 executeBatch 三条超长插入的返回值与 ps.getWarnings()
PG 直接报错
PostgreSQL 插入超长字符串到 varchar(3):ERROR: value too long(22001),不是 SQLWarning

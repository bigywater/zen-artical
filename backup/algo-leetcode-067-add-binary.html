LeetCode 67. 二进制求和

给定两个用字符串表示的二进制数，返回它们的和（同样是二进制字符串）。做法就是竖式加法：从两个字符串的最低位（最右边）往左，逐位相加，每一位的结果是 (a位 + b位 + 进位) % 2，新的进位是 (a位 + b位 + 进位) / 2；两个数都走完之后如果还有进位，还要再写一位。这道题的重点和上一题、字符串相乘一样：输入可以有一万位，不能转成语言内置的整数。本文用真实运行展示 Java 的 long 和 JavaScript 的 parseInt 各自怎么失败，给出五种语言的实现，并把逐位相加做成分步演示。

陷阱：内置整数装不下，或者精度丢失

如果想偷懒，用语言内置的函数把字符串解析成整数，相加，再转回二进制字符串，输入变长时就会出问题：Java 的 long 最多 63 位，更长的字符串会抛异常；JavaScript 的 Number 是双精度浮点，超过 53 位就会丢失末位。下面是真实运行的结果，JavaScript 那一组用的是 60 个 1 加 "10"（真实的和是 2^60 + 1）：

Java 里 Long.parseLong 解析 70 个 1 时直接抛出 NumberFormatException。JavaScript 里 parseInt 相加的结果末位是 0，而用 BigInt 得到的正确结果末位是 1，两者不同：2^60 + 1 超出了双精度浮点能精确表示的范围，被舍入成了 2^60。本文的逐位相加不受位数限制，结果与 Python 大整数的结果一致。

逐位相加：五种语言的实现

两个指针 i、j 分别指向 a、b 的最后一位，carry 是进位。只要 i 或 j 还没走完，或者还有进位，就继续：把当前两位（走完的那个数按 0 计）和进位相加得 s，这一位写 s % 2，进位变成 s / 2。结果是从低位到高位生成的，最后要反转。Python、Java、Go、JavaScript、C++ 都是真实编译运行的。

Python · 解法代码def solve(a, b): i, j, carry = len(a) - 1, len(b) - 1, 0 res = [] while i >= 0 or j >= 0 or carry: # 两个数都走完了，还要看最后的进位 s = carry if i >= 0: s += int(a[i]) i -= 1 if j >= 0: s += int(b[j]) j -= 1 res.append(str(s % 2)) # 这一位的结果 carry = s // 2 # 进位 return "".join(reversed(res))

Java · 解法代码class Solution { public String addBinary(String a, String b) { int i = a.length() - 1, j = b.length() - 1, carry = 0; StringBuilder sb = new StringBuilder(); while (i >= 0 || j >= 0 || carry > 0) { // 两个数都走完了，还要看最后的进位 int s = carry; if (i >= 0) s += a.charAt(i--) - '0'; if (j >= 0) s += b.charAt(j--) - '0'; sb.append(s % 2); // 这一位的结果 carry = s / 2; // 进位 } return sb.reverse().toString(); } }

Go · 解法代码func addBinary(a string, b string) string { i, j, carry := len(a)-1, len(b)-1, 0 res := []byte{} for i >= 0 || j >= 0 || carry > 0 { // 两个数都走完了，还要看最后的进位 s := carry if i >= 0 { s += int(a[i] - '0') i-- } if j >= 0 { s += int(b[j] - '0') j-- } res = append(res, byte('0'+s%2)) // 这一位的结果 carry = s / 2 // 进位 } for l, r := 0, len(res)-1; l < r; l, r = l+1, r-1 { res[l], res[r] = res[r], res[l] } return string(res) }

JavaScript · 解法代码function addBinary(a, b) { let i = a.length - 1, j = b.length - 1, carry = 0; const res = []; while (i >= 0 || j >= 0 || carry > 0) { // 两个数都走完了，还要看最后的进位 let s = carry; if (i >= 0) s += Number(a[i--]); if (j >= 0) s += Number(b[j--]); res.push(s % 2); // 这一位的结果 carry = Math.floor(s / 2); // 进位 } return res.reverse().join(""); }

分步演示：1011 + 110

下面的演示用 1011（十进制 11）加 110（十进制 6），和应该是 10001（十进制 17）。最低位 1 + 0 = 1，写 1；下一位 1 + 1 = 2，写 0 进 1；再下一位 1（进位）+ 0 + 1 = 2，写 0 进 1；最高位 1（进位）+ 1 = 2，写 0 进 1；两个数都走完了，还剩一个进位 1，再写一位。每一帧都是把上面的解法在这组输入上真实执行记录下来的，运行器还检查了演示的最终结果与 solve 的返回值一致。

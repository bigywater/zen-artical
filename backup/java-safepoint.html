Safepoint:所有线程为什么会短暂停下来

所有应用线程在 GC 等操作时都要先「停到安全点」。停下来要多久,取决于最慢的那个线程什么时候遇到安全点检查。这篇用真实的日志和一个故意去掉安全点检查的计数循环,看到达安全点的时间怎么变成一个线程拖住所有线程。

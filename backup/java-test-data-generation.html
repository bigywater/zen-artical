测试数据生成:随机不等于不可复现

随机的测试数据不等于不可复现的测试数据——前提是你控制了种子、线程与派生方式。这篇逐项量出:哪些随机源能设种子,种子跨 JDK 是否稳定,共享随机数在多线程与并行流里为什么会丢失可复现性,以及不能拿什么当种子。

3 个 JDK
Random / SplittableRandom / L64X128MixRandom / shuffle 的同种子输出逐字相同(17、21、27)
6 种
8 线程共享一个 Random(42) 时 6 次运行得到的各线程取值组合数(总和都是 3984002)
1 种 vs 5 种
并行流 5 次运行:按下标派生种子的结果哈希种数 vs 共享 Random 的哈希种数

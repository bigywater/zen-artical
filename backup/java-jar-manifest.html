签名

实测 · 本机执行输出 
  jarsigner 输出: jar signed. | Warning: | The signer's certificate is self-signed.
  签名后 jar 里的文件: ['META-INF/MANIFEST.MF', 'META-INF/DEV.SF', 'META-INF/DEV.EC', 'META-INF/', 'App.class']
  jarsigner -verify: jar verified.
  META-INF/DEV.SF 的开头:
    Signature-Version: 1.0
    Created-By: 21.0.12.1 (Homebrew)
    SHA-384-Digest-Manifest: A7fVQmfYgpWmatD61P+7Zkg87YQ+ploPHOenIgw0Agsxg4I
     jNNnDeBbW1PfCVQUZ
  替换了 App.class 之后 jarsigner -verify: jarsigner: java.lang.SecurityException: SHA-384 digest error for App.class
  java -jar tampered.jar: Exception in thread "main" java.lang.SecurityException: SHA-384 digest error for App.class

多版本 JAR

实测 · 本机执行输出 
  jar 创建: 成功
  jar 里的文件: ['META-INF/', 'META-INF/MANIFEST.MF', 'Main.class', 'Ver.class', 'META-INF/versions/17/', 'META-INF/versions/17/Ver.class', 'META-INF/versions/21/', 'META-INF/versions/21/Ver.class']
  manifest 里有 Multi-Release: True
17:Ver.name() = versions/17 的实现
21:Ver.name() = versions/21 的实现
27:Ver.name() = versions/21 的实现
  JDK 21,但 -Djdk.util.jar.enableMultiRelease=false:21:Ver.name() = base(Java 8 风格的基线实现)

send_from_directory

实测 · 本机执行输出 
  GET /dir/report.txt              → 200
  GET /dir/../secret.txt           → 404
  GET /dir/..%2fsecret.txt         → 404
  GET /dir/%2e%2e/secret.txt       → 404
  GET /dir//etc/passwd             → 308
  GET /dir/sub/../report.txt       → 200
  GET /dir/nope.txt                → 404
  GET /dir-rel/report.txt          → 200
  找不到文件 send_file("data/nope.txt") → 视图里抛出 FileNotFoundError → 经过 HTTP 是 500
  找不到文件 send_from_directory(目录, "nope.txt") → NotFound → HTTP 404

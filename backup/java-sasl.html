Java SASL:可插拔的认证与安全层

SASL 把认证机制从协议里抽出来。这篇不连任何外部服务,直接让 JDK 自带的客户端与服务端互相认证,看有哪些机制、报文怎么走、协商出的保护层是什么,以及 unwrap 在遇到篡改时的真实行为。

4 个服务端机制
JDK 21 的 SaslServerFactory 提供的机制:DIGEST-MD5、NTLM、CRAM-MD5、GSSAPI(没有 PLAIN 与 SCRAM)
